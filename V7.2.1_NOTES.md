# Shuffle+ v7.2.1 — Correctif de connexion et de navigation

## Correction principale

La v7.2.0 pouvait afficher l'erreur JavaScript `groups is not defined` juste après la connexion Spotify.

La cause était un reliquat du refactoring du menu :

- la navigation utilise maintenant `APP_MENU_GROUPS`, importé depuis `core/app-menu.js` ;
- `renderAppMenu()` utilisait encore l'ancien identifiant local `groups` ;
- le panneau de diagnostic utilisait par erreur les groupes du menu à la place de ses propres catégories.

La v7.2.1 corrige ces deux références.

## Fiabilisation

Deux tests de régression empêchent désormais le retour de cette erreur :

- le menu doit utiliser `APP_MENU_GROUPS` ;
- le diagnostic doit conserver son tableau local `groups`.

## Mise à jour PWA

Le numéro de version et le cache du Service Worker passent à `7.2.1`, afin que les navigateurs et les applications installées téléchargent réellement le fichier corrigé.

Aucune donnée locale, playlist, préférence ou autorisation Spotify n'est modifiée.
