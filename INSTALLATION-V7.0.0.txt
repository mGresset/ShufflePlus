Shuffle+ v7.0.0 — Installation

1. Sauvegarder le dossier actuellement publié.
2. Remplacer les fichiers du dépôt par ceux du ZIP.
3. Publier :

   git add .
   git commit -m "v7.0.0 - Stabilisation et navigation"
   git pull --rebase origin main
   git push origin main

4. Attendre la publication GitHub Pages.
5. Dans Shuffle+ : Réglages → Rechercher une mise à jour.
6. Fermer complètement Safari ou la PWA puis relancer Shuffle+.
7. Vérifier que « Version 7.0.0 » est affichée.

Le Centre de diagnostic se trouve dans Réglages.
