# Shuffle+ v7.3.0 — iPhone prioritaire et liste de lecture

## Objectif principal

Shuffle+ revient à son besoin fondateur : lancer rapidement une playlist Spotify personnelle en mode aléatoire depuis un raccourci iOS, tout en conservant les fonctions ajoutées au fil des versions.

## Appareil Spotify préféré

La rubrique **Mix & iOS** permet désormais :

- de détecter les appareils Spotify disponibles ;
- d’enregistrer un iPhone comme appareil prioritaire ;
- de coller manuellement un `device_id` lorsque nécessaire ;
- de retrouver l’appareil d’abord par identifiant, puis par nom et type ;
- de conserver ces informations uniquement dans le stockage local du navigateur.

Un raccourci configuré sur « iPhone préféré enregistré » utilise cet appareil en priorité. Les anciennes commandes configurées sur « iPhone ou smartphone » bénéficient également de l’appareil enregistré lorsqu’il existe.

## Lancement iOS plus fiable

La séquence de lancement est maintenant contrôlée :

1. recherche répétée de l’iPhone ;
2. tentative de transfert Spotify Connect ;
3. activation préalable du shuffle ;
4. lancement de la playlist sur le `device_id` ciblé ;
5. seconde activation du shuffle ;
6. vérification de l’appareil réellement actif et de l’état de lecture ;
7. seconde tentative automatique si nécessaire.

Pour une nouvelle commande, le shuffle est activé par défaut et Shuffle+ choisit un point de départ aléatoire dans la playlist lorsque le nombre de titres est connu. L’option « Forcer le premier morceau » reste disponible.

Une commande peut également ouvrir automatiquement le mode conduite après le démarrage de la musique.

## Raccourci iOS recommandé

Le centre de commandes indique maintenant la séquence conseillée dans l’application Raccourcis :

1. **Ouvrir l’app** → Spotify ;
2. **Attendre** → 1 seconde ;
3. **Ouvrir les URL** → lien de la commande Shuffle+.

Cette première ouverture réveille Spotify Connect avant que Shuffle+ recherche l’iPhone.

## Liste de lecture en mode conduite

Un bouton **Liste de lecture** est ajouté au mode conduite. Il ouvre un panneau adapté au mobile avec :

- le morceau actuellement joué ;
- jusqu’à 20 prochains éléments de la file Spotify ;
- la pochette, le titre, l’artiste et la durée ;
- une actualisation manuelle ;
- une actualisation automatique lorsque le panneau est ouvert.

La liste reflète la file Spotify active et peut évoluer lorsque le shuffle ou Spotify Connect change l’ordre.

## Compatibilité

- aucune suppression des raccourcis existants ;
- aucune migration obligatoire des sauvegardes ;
- Spotify Premium reste requis pour le contrôle de lecture à distance ;
- l’iPhone doit apparaître comme appareil Spotify Connect ou disposer d’un `device_id` encore valable ;
- le Service Worker passe à `shuffleplus-v7.3.0` afin de renouveler le cache PWA.
