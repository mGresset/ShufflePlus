# Shuffle+ v6.9.0 — Modes d’utilisation

## Nouvelle rubrique Modes

Cinq configurations prêtes à l’emploi sont disponibles :

- Quotidien : accueil et recommandations équilibrées ;
- Conduite : interface voiture, scène Conduite et écran actif demandé ;
- Sport : scène Sport, lecture automatique et accent orange ;
- Soirée : scène Party, découverte modérée et accent rose ;
- Découverte : suggestions plus variées, sans lecture automatique imposée.

Un mode peut adapter la page ouverte, la scène active, la couleur,
le niveau de découverte et les réglages du mode voiture. Il ne supprime
aucun mix, aucune scène et aucune préférence existante.

## Assistant

Exemples :

- `Active le mode Sport`
- `Active le mode Conduite`
- `Passe en mode Découverte`

## Intégrations

- Guide simplifié ;
- aide contextuelle ;
- recherche universelle ;
- sauvegarde et synchronisation complète.

Le serveur Node.js reste inchangé.
