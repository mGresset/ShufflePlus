# Shuffle+ v7.3.2 — Interface iPhone stabilisée

## Objectif

Corriger les chevauchements observés sur Safari iOS et dans la PWA installée, sans modifier les données, la connexion Spotify ni le fonctionnement des raccourcis.

## Corrections

### Bandeau de mise à jour

- positionné au-dessus de la navigation mobile fixe ;
- `z-index` supérieur à celui du menu inférieur ;
- prise en charge de `env(safe-area-inset-bottom)` ;
- hauteur maximale adaptée au viewport dynamique iOS ;
- défilement interne si le contenu devient trop haut ;
- boutons de 44 px minimum pour une zone tactile correcte ;
- boutons « Mettre à jour » et « Plus tard » affichés côte à côte sur mobile.

### En-tête connecté

- quatre zones réservées sur une seule ligne : marque, état réseau, bienvenue et déconnexion ;
- bouton de déconnexion maintenu à droite ;
- message de bienvenue tronqué avec des points de suspension lorsque le nom est long ;
- réduction progressive des dimensions sous 390 px ;
- conservation d’une seconde ligne uniquement pour les messages d’état éventuels.

## Compatibilité

- aucune migration de données ;
- aucune nouvelle autorisation Spotify ;
- préférences, mix, appareil iPhone préféré et statistiques conservés ;
- mise à jour du cache PWA vers `shuffleplus-v7.3.2`.
