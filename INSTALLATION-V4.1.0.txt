Shuffle+ v4.1.0 — Smart Queue

1. Sauvegarder la version actuelle.
2. Remplacer tous les fichiers par ceux du ZIP.
3. Publier :

   git add .
   git commit -m "v4.1.0 - Smart Queue"
   git pull --rebase origin main
   git push origin main

4. Dans Shuffle+ installé, ouvrir Réglages puis rechercher une mise à jour.
5. Accepter le bandeau de mise à jour, ou fermer et rouvrir complètement l’application.

Vérification : la page doit afficher Version 4.1.0 et le résultat d’un mix doit contenir le panneau « Smart Queue 4.1 ».
