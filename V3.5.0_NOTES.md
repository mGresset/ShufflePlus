# Shuffle+ v3.5.0 — Adaptation automatique optionnelle

## Nouveautés

- activation explicite, désactivée par défaut ;
- confiance minimale réglable de 60 % à 95 % ;
- minimum de choix concordants réglable ;
- aperçu du prochain changement possible ;
- application uniquement au lancement réel d’Adaptive DJ ;
- journal des changements ;
- retour arrière manuel ;
- retour arrière automatique en cas d’échec ;
- export et import des nouveaux réglages.

## Garde-fous

- Adaptive Learning doit être actif ;
- les simulations ne modifient rien ;
- les suggestions ignorées restent protégées ;
- les lancements automatiques ne renforcent pas leur propre confiance ;
- un choix manuel ultérieur bloque l’annulation afin de ne pas être écrasé.

## Architecture

Aucun nouveau module JavaScript n’a été ajouté. La logique reste intégrée dans `app.js`.
