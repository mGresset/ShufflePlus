Shuffle+ v7.3.0 — Installation rapide

1. Extraire ShufflePlus-v7.3.0-patch.zip à la racine du dépôt v7.2.1.
2. Exécuter : npm run validate
3. Exécuter : npm start
4. Tester http://127.0.0.1:5500/
5. Dans Mix & iOS, enregistrer l’iPhone préféré.
6. Configurer une commande avec shuffle activé.
7. Créer le raccourci iOS : ouvrir Spotify, attendre 1 s, ouvrir l’URL Shuffle+.
8. Publier la branche release/7.3.0 puis fusionner vers main.

Guide complet : DEPLOIEMENT-V7.3.0.md
