SHUFFLE+ v7.4.0 — INSTALLATION RAPIDE

1. Extraire ShufflePlus-v7.4.0-patch.zip à la racine du dépôt v7.3.2.
2. Autoriser le remplacement des fichiers existants.
3. Ouvrir le terminal Visual Studio Code.
4. Exécuter : npm run validate
5. Exécuter : npm start
6. Tester http://127.0.0.1:5500/
7. Ouvrir Mix & iOS puis configurer le panneau Dynamic Lyrics.
8. Créer sur l’iPhone un raccourci nommé « Shuffle+ Dynamic Lyrics » qui ouvre Dynamic Lyrics.
9. Tester le bouton Dynamic Lyrics depuis Shuffle+.
10. Publier la branche release/7.4.0 puis la fusionner dans main.

Aucune nouvelle Redirect URI Spotify n’est nécessaire.
Aucun Client ID Dynamic Lyrics ne doit être ajouté dans Shuffle+.
