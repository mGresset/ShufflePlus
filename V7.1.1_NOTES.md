# Shuffle+ v7.1.1 — Fiabilité Spotify et déploiement automatique

Date : 30 juillet 2026

## Objectif

Cette version corrige les changements récents de Spotify sans modifier le moteur de mélange ni l’organisation fonctionnelle de Shuffle+.

## Nouveautés

- Gestion explicite de l’erreur OAuth `invalid_grant`.
- Suppression des tokens expirés et affichage d’un bouton « Se reconnecter à Spotify ».
- Enregistrement local de la date de l’autorisation initiale Spotify.
- Verrou de renouvellement : plusieurs appels simultanés utilisent une seule requête de refresh token.
- Conservation de la session lors d’une erreur réseau temporaire de renouvellement.
- Lecture du champ Spotify `error.reason`.
- Arrêt immédiat des nouvelles tentatives en cas de `QUOTA_EXCEEDED`.
- Maintien des nouvelles tentatives classiques pour les rate limits avec `Retry-After`.
- Adresse locale officielle : `http://127.0.0.1:5500/`.
- Workflow GitHub Actions : vérification, tests, build puis déploiement GitHub Pages.
- Commandes VS Code : démarrage local, tests et build.

## Tests ajoutés

- mémorisation de la date d’autorisation ;
- expiration `invalid_grant` ;
- renouvellement simultané dédupliqué ;
- quota Spotify non retenté ;
- rate limit classique retenté après `Retry-After` ;
- validation syntaxique de tous les fichiers JavaScript ;
- validation de la cohérence du numéro de version ;
- tests existants du serveur de synchronisation.
