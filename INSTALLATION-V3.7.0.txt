Shuffle+ v3.7.0 — Installation

1. Sauvegarder le dossier actuel.
2. Remplacer les fichiers par ceux de cette archive.
3. Vérifier dans index.html :
   <script type="module" src="./app.js?v=3.7.0"></script>
4. Publier :

   git add .
   git commit -m "v3.7.0 - Historique enrichi et corrections"
   git pull --rebase origin main
   git push origin main

Après publication :
- PC : Ctrl + F5
- iPhone : fermer Safari puis rouvrir.
