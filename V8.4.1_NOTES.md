# Shuffle+ v8.4.1 — Notes de version

## Objectif

La v8.4.1 corrige deux incohérences visuelles observées après la v8.4.0 : la saisie du Client ID Spotify et les composants verts de la rubrique d’installation PWA. Le fonctionnement Spotify, les raccourcis Apple, les données locales et le serveur Railway restent inchangés.

## Connexion Spotify

- regroupement de l’adresse de redirection et du Client ID dans un parcours visuel en deux étapes ;
- ajout d’un titre et d’une explication avant la saisie du Client ID ;
- rappel explicite de ne jamais renseigner le Client Secret ;
- champ Client ID en pleine largeur ;
- aide liée au champ par `aria-describedby` ;
- boutons d’enregistrement et d’ouverture de Spotify for Developers placés sous le champ ;
- disposition mobile en une seule colonne.

## Installation PWA et thèmes

- badge d’installation relié à `--accent` et `--accent-rgb` ;
- panneaux « Cache de l’interface », « Ressources hors connexion » et « Mode application » reliés à la palette active ;
- suppression des emojis verts fixes au profit d’indicateurs `✓`, `×` et `i` ;
- action « Installer Shuffle+ » rendue explicitement principale ;
- instructions et recherche de mise à jour rendues secondaires ou discrètes ;
- guide d’installation et bandeau de mise à jour harmonisés avec le thème actif ;
- vert conservé uniquement lorsqu’un véritable état sémantique l’exige ailleurs dans l’application.

## Compatibilité

- aucune migration de stockage ;
- aucune nouvelle variable Railway ;
- profils, mix et raccourcis Apple conservés ;
- serveur de synchronisation inchangé ;
- cache PWA renouvelé en `shuffleplus-v8.4.1`.

## Validation

- 134 tests applicatifs réussis ;
- tests serveur réussis ;
- build de production réussi ;
- distribution v8.4.1 vérifiée ;
- test du serveur local réussi.

Le navigateur automatisé de l’environnement bloque les adresses locales et `file://`. Un contrôle visuel manuel reste donc recommandé sur navigateur réel et sur iPhone.
