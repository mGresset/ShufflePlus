Shuffle+ v3.6.0 — Installation

1. Sauvegarder la version actuelle.
2. Remplacer les fichiers par ceux de cette archive.
3. Vérifier que index.html charge :
   <script type="module" src="./app.js?v=3.6.0"></script>
4. Publier :

   git add .
   git commit -m "v3.6.0 - Intelligence Dashboard"
   git pull --rebase origin main
   git push origin main

5. Après publication :
   - PC : Ctrl + F5
   - iPhone : fermer Safari complètement puis rouvrir.

Les statistiques v3.6 commencent à se remplir à partir des prochains mix générés et lancements. Les historiques v3.5 restent conservés, mais ne contiennent pas tous les nouveaux détails analytiques.
