# Shuffle+ v7.4.3 — Optimisation du quota Spotify

## Objectif

La v7.4.3 réduit les appels inutiles à la Web API Spotify et améliore le comportement de Shuffle+ lorsqu’un quota ou un rate limit renvoie une erreur HTTP 429.

## Gestionnaire central des requêtes

Un nouveau module `core/spotify-request-manager.js` centralise les appels Spotify :

- déduplication de deux lectures identiques lancées simultanément ;
- cache mémoire court pour le lecteur, les appareils, la file et la bibliothèque ;
- invalidation automatique du cache après une commande de lecture ou une écriture ;
- limite de 80 entrées en mémoire ;
- compteur des appels réseau, réponses réutilisées et requêtes regroupées.

Le cache est uniquement conservé en mémoire pendant la session. Il ne stocke aucun jeton supplémentaire et ne modifie pas les données Spotify.

## Protection après une erreur 429

- `QUOTA_EXCEEDED` n’est jamais retenté automatiquement ;
- une pause globale de cinq minutes est appliquée si Spotify ne fournit pas de délai ;
- `Retry-After` reste prioritaire lorsqu’il est présent ;
- les autres rubriques ne continuent plus à envoyer de nouveaux appels pendant la pause ;
- une réponse déjà présente dans le cache mémoire reste utilisable ;
- le message indique que Shuffle+ a volontairement suspendu les appels.

## Réduction des actualisations automatiques

- mode Conduite : lecture actualisée toutes les 12 secondes au lieu de 8 ;
- file de lecture : actualisée au maximum toutes les 30 secondes lorsqu’elle est ouverte ;
- aucun minuteur Spotify actif lorsque Shuffle+ passe en arrière-plan ;
- analyse des dates de playlists limitée à une requête à la fois, avec un délai entre les playlists ;
- l’analyse s’arrête immédiatement si Spotify signale une erreur 429.

## Diagnostic

Le Centre de diagnostic affiche désormais :

- le nombre d’appels Spotify réellement envoyés ;
- le nombre de réponses servies depuis le cache ;
- les requêtes identiques regroupées ;
- l’état d’une éventuelle pause de quota ;
- le temps restant avant la reprise.

Le rapport exporté ne contient toujours aucun titre, aucune playlist, aucun jeton Spotify et aucun identifiant personnel.

## Compatibilité

- aucune migration des playlists, mix ou réglages ;
- appareil iPhone préféré conservé ;
- intégration Dynamic Lyrics inchangée ;
- connexion Spotify et raccourcis iOS inchangés ;
- cache PWA renouvelé en v7.4.3.
