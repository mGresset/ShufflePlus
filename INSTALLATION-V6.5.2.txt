Shuffle+ v6.5.2 — Installation

1. Remplacer les fichiers du dépôt par ceux de cette archive.
2. Publier :

   git add .
   git commit -m "v6.5.2 - Wake Lock reliability"
   git pull --rebase origin main
   git push origin main

3. Dans Shuffle+ : Réglages → Rechercher une mise à jour.
4. Fermer complètement Safari ou la PWA, puis relancer.
5. Dans le mode voiture, vérifier que le bouton Écran devient vert et affiche « Écran actif ».
