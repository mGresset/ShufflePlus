Shuffle+ v6.5.0 — Installation

1. Remplacer les fichiers du dépôt par ceux du ZIP.
2. Publier :

   git add .
   git commit -m "v6.5.0 - Objectifs hebdomadaires"
   git pull --rebase origin main
   git push origin main

3. Attendre GitHub Pages.
4. Ouvrir Réglages → Rechercher une mise à jour.
5. Fermer complètement la PWA puis la relancer.

Le nouvel onglet s’appelle « Objectifs ».
