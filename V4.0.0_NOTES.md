# Shuffle+ v4.0.0 — PWA installable

## Nouveautés

- installation comme application sur ordinateur et mobile ;
- manifeste web et jeu complet d’icônes ;
- service worker avec cache de l’interface ;
- ouverture de l’application hors connexion ;
- bandeau réseau ;
- interface d’installation dans l’en-tête et les réglages ;
- instructions spécifiques à Safari sur iPhone et iPad ;
- recherche manuelle de mise à jour ;
- notification lorsqu’une nouvelle version est prête ;
- raccourci Adaptive DJ dans le manifeste.

## Limite volontaire

Le cache PWA ne remplace pas Internet pour Spotify. Le compte, les playlists, les appareils et la lecture restent fournis par l’API Spotify.
