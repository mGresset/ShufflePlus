Shuffle+ v7.2.0 — Installation et déploiement

Mise à niveau recommandée depuis la v7.1.1 : utiliser l’archive patch.

1. Sauvegarder le dépôt local actuel.

2. Décompresser le patch à la racine du dépôt en remplaçant les fichiers.
   Conserver le dossier .git du dépôt local.

3. Dans le terminal Visual Studio Code :
   node --version
   npm run validate
   npm start

4. Tester sur :
   http://127.0.0.1:5500/

5. Vérifier au minimum : connexion, Accueil, Ma musique, Mix & iOS,
   Pour toi, Statistiques, Réglages et mode Conduite.

6. Publier de préférence par une branche :
   git checkout -b release/7.2.0
   git add .
   git commit -m "Release Shuffle+ v7.2.0"
   git push -u origin release/7.2.0

7. Créer puis fusionner la Pull Request vers main. La Pull Request est testée,
   mais seul le push final sur main déclenche le déploiement GitHub Pages.

8. Après validation :
   git tag -a v7.2.0 -m "Shuffle+ v7.2.0"
   git push origin v7.2.0

Guide détaillé : DEPLOIEMENT-V7.2.0.md
