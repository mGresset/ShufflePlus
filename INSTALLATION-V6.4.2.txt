Shuffle+ v6.4.2 — Installation

1. Remplacer les fichiers du dépôt par ceux de cette archive.
2. Publier :

   git add .
   git commit -m "v6.4.2 - Menu PC sur une ligne"
   git pull --rebase origin main
   git push origin main

3. Attendre la publication GitHub Pages.
4. Dans Shuffle+ : Réglages → Rechercher une mise à jour.
5. Fermer complètement la PWA puis la relancer.
6. Vérifier que « Version 6.4.2 » est affichée.

Le tri initial reste « Modifiées récemment ».
