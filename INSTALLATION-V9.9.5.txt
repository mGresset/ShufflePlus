SHUFFLE+ V9.9.5 — INSTALLATION

1. Conserver le dossier caché .git de votre dépôt local.
2. Remplacer les autres fichiers par ceux de cette archive.
3. Exécuter : npm.cmd run validate
4. Exécuter : git add -A
5. Exécuter : git commit -m "Release Shuffle+ v9.9.5 - candidate v10"
6. Exécuter : git push origin main
7. Fermer puis rouvrir la PWA après le déploiement.
