# Shuffle+ v7.8.0 — Navigation simplifiée et mise à jour unique

## Navigation principale réduite

La barre principale contient désormais cinq rubriques :

- **Accueil** ;
- **Musique** ;
- **Créer** ;
- **Raccourcis** ;
- **Réglages**.

Les pages historiques restent disponibles et sont regroupées ainsi :

- Musique : Ma musique, Pour toi, Statistiques, Objectifs et Analyses ;
- Créer : Mix & iOS, Assistant, Adaptive DJ et Modes ;
- Raccourcis : Mes raccourcis et Conduite sur iOS/iPadOS ;
- Réglages : Réglages, Guide et aide.

Les deux fonctions les plus utiles du groupe sont visibles directement. Les autres sont accessibles avec **Voir plus**. Lorsqu’une page avancée est ouverte, elle apparaît aussi dans la barre contextuelle afin de rester identifiable.

## Compatibilité

Les identifiants historiques de pages ne changent pas. Une ancienne URL comme :

```text
?view=statistics
```

ouvre toujours Statistiques et sélectionne maintenant le menu parent **Musique**.

Aucune donnée utilisateur, aucun profil, aucun mix et aucun raccourci ne sont migrés ou supprimés.

## Mise à jour PWA sans second bandeau

Le Service Worker répond maintenant à une demande de version explicite. Shuffle+ peut donc distinguer :

- une version réellement plus récente ;
- la version déjà chargée ;
- la version que l’utilisateur vient d’appliquer.

Après le clic sur **Mettre à jour** :

1. le bouton passe à **Mise à jour…** ;
2. la version cible est mémorisée dans la session ;
3. Shuffle+ attend `controllerchange` ;
4. l’application se recharge une seule fois ;
5. le bandeau reste masqué si la version active correspond déjà à la version proposée.

Un rechargement de secours intervient uniquement si iOS ne signale pas le changement de contrôleur dans les douze secondes.
