# Shuffle+ v8.5.0 — Notes de version

## Objectif

La v8.5.0 consolide l’architecture de Shuffle+ sans modifier le parcours Spotify, les profils de lancement, les raccourcis Apple ni la synchronisation Railway. Le travail porte sur trois axes : découpage progressif de `app.js`, performances des longues pages et sécurité du navigateur.

## Architecture

Quatre responsabilités sont maintenant isolées dans des modules indépendants :

- `core/pwa-install-ui.js` : état, guide et panneau de l’installation PWA ;
- `core/spotify-setup-ui.js` : affichage de la configuration Spotify et panneau Client ID des réglages ;
- `core/runtime-performance.js` : optimisation des images, rendu différé et mesures de démarrage ;
- `core/security-policy.js` : politique CSP, diagnostic de sécurité et ouverture contrôlée des liens externes.

Cette extraction retire plusieurs blocs de rendu de `app.js` et rend leurs comportements testables séparément. Le fichier principal reste volumineux, mais sa réduction se poursuit sans réécriture globale risquée.

## Performances

- préconnexion aux domaines d’autorisation et d’API Spotify ;
- chargement différé automatique des pochettes secondaires ;
- priorité conservée pour les médias du header, de la connexion et de la lecture en cours ;
- `content-visibility: auto` sur les panneaux longs situés hors écran ;
- optimisation également appliquée aux éléments ajoutés dynamiquement ;
- collecte légère des temps de navigation et du volume de ressources dans l’état de diagnostic ;
- script de récupération chargé avec `defer` ;
- quatre nouveaux modules intégrés au cache du Service Worker.

## Sécurité

- ajout d’une politique Content Security Policy comprenant 15 directives ;
- scripts limités aux fichiers de Shuffle+ ;
- scripts HTML inline, `eval`, objets et frames interdits ;
- connexions HTTPS conservées pour Spotify et l’adresse Railway configurable ;
- politique de référence `no-referrer` ;
- ouverture des liens Spotify limitée à `developer.spotify.com` et `open.spotify.com` ;
- mêmes en-têtes de sécurité servis par le serveur local ;
- nouveau contrôle `scripts/check-security.mjs` exécuté par `npm run check`.

La directive de style conserve `unsafe-inline` parce que certaines visualisations existantes utilisent encore des variables et dimensions CSS dynamiques. Leur migration pourra être réalisée progressivement dans une version ultérieure.

## Compatibilité

- aucune migration de stockage ;
- aucune nouvelle variable Railway ;
- Client ID Spotify personnel conservé ;
- profils, mix, historique et thèmes conservés ;
- raccourci Apple universel inchangé ;
- serveur de synchronisation inchangé ;
- cache PWA renouvelé en `shuffleplus-v8.5.0`.

## Validation

- 143 tests applicatifs réussis ;
- tests du serveur de synchronisation réussis ;
- contrôle statique CSP réussi ;
- build de production réussi ;
- distribution v8.5.0 vérifiée ;
- test du serveur local réussi.

Un contrôle manuel reste recommandé sur navigateur réel et iPhone pour la connexion Spotify, l’installation PWA, le mode conduite et le changement de thème.
