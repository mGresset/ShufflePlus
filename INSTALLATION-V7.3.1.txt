Shuffle+ v7.3.1 — Installation rapide

1. Extraire ShufflePlus-v7.3.1-patch.zip à la racine du dépôt v7.3.0.
2. Autoriser le remplacement des fichiers.
3. Ouvrir le terminal Visual Studio Code.
4. Exécuter : npm run validate
5. Exécuter : npm start
6. Tester http://127.0.0.1:5500/
7. Vérifier le lien « Connexion bloquée ? ».
8. Publier la branche hotfix/7.3.1 puis fusionner vers main.
9. Vérifier GitHub Pages et la version 7.3.1.

Guide complet : DEPLOIEMENT-V7.3.1.md
