Shuffle+ v4.6.0 — Installation

1. Sauvegarder le dossier actuellement publié.
2. Remplacer tous les fichiers par ceux du ZIP.
3. Vérifier que le nouveau fichier SYNC_API_CONTRACT.md est présent.
4. Publier :

   git add .
   git commit -m "v4.6.0 - Préparation synchronisation"
   git pull --rebase origin main
   git push origin main

5. Dans la PWA : Réglages → Rechercher une mise à jour.
6. Ouvrir Réglages → Synchronisation multi-appareils.

La v4.6 reste locale : aucun serveur n’est contacté.
