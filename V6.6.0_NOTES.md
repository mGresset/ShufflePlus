# Shuffle+ v6.6.0 — Guide simplifié

## Nouvelle rubrique Guide

Cette version ajoute un manuel directement dans l’application. Il explique simplement :

- le rôle de chaque catégorie ;
- le parcours conseillé pour débuter ;
- les différences entre une source, un mix, un profil et une scène ;
- quelques réponses aux problèmes les plus fréquents.

Chaque carte possède un bouton qui ouvre directement la rubrique concernée.

Le guide reste volontairement court. Deux boutons permettent d’ouvrir ou de télécharger le fichier `README.md` pour consulter la documentation détaillée.

## Compatibilité

- aucune nouvelle autorisation Spotify ;
- aucun changement du serveur Node.js ;
- navigation PC et iOS conservée ;
- tri par défaut « Modifiées récemment » conservé ;
- correctif Wake Lock conservé.
