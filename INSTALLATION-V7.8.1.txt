SHUFFLE+ V7.8.1 — INSTALLATION RAPIDE

BASE REQUISE
- Shuffle+ v7.8.0 stable.

1. Décompresser ShufflePlus-v7.8.1-patch.zip dans le dépôt v7.8.0.
2. Exécuter : Remove-Item .\startup-recovery-7.8.0.js -ErrorAction SilentlyContinue
3. Exécuter : npm run validate
4. Exécuter : npm start
5. Tester : http://127.0.0.1:5500/
6. Tester Conduite : http://127.0.0.1:5500/?debug_ios=1
7. Vérifier Réglages > Apparence et la couleur personnalisée.
8. Vérifier que le mode conduite reprend la couleur active.
9. Vérifier que Raccourcis iOS apparaît en premier dans Créer.
10. Publier la branche hotfix/7.8.1 puis fusionner la Pull Request.

AUCUNE DONNÉE SUPPRIMÉE
- Client ID et connexion Spotify conservés.
- Mix, profils, raccourcis et iPhone préféré conservés.
- Thème existant migré automatiquement.
- Réglages, statistiques et cache hors connexion conservés.
