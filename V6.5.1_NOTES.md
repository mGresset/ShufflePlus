# Shuffle+ v6.5.1 — Mode voiture iPhone sans défilement

## Objectif

Le mode voiture a été reconstruit pour rester entièrement visible dans Safari sur un grand iPhone Pro Max, sans devoir faire défiler la page pour atteindre les commandes.

## Modifications

- utilisation de la hauteur réellement visible de Safari via `visualViewport.height` avec secours `100dvh` ;
- prise en charge de `viewport-fit=cover` et des zones sûres iPhone ;
- masquage de l’en-tête et de la navigation générale pendant le mode voiture ;
- interface compacte en portrait :
  - titre en cours ;
  - Adaptive DJ ;
  - pause/reprise ;
  - titre suivant ;
  - commande vocale ;
  - J’aime / Pas maintenant ;
  - actualisation, écran allumé et actualisation automatique ;
- compression supplémentaire lorsque les barres Safari réduisent la hauteur visible ;
- disposition paysage dédiée ;
- maintien de cibles tactiles adaptées et des libellés accessibles.

## Limite de validation

Les contrôles statiques et JavaScript sont vérifiés. La hauteur exacte dépend de l’état des barres Safari et doit être confirmée sur l’iPhone réel après publication.
