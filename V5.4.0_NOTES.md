# Shuffle+ v5.4.0 — Adaptive DJ 2.0

## Contenu de la version

- Scènes musicales personnalisables intégrées dans l’onglet Adaptive DJ.
- 6 scènes prêtes à l’emploi : Matin, Focus, Chill, Conduite, Sport, Party.
- Réglages par scène : mix, profil, énergie, variété, découverte, durée, autoplay.
- Boutons par scène : lancer, copier l’URL iOS, définir la scène active.
- Nouvelle automatisation URL : `action=scene`.
- Sauvegarde et restauration des scènes dans les backups Shuffle+.

## Déploiement

```bash
git add .
git commit -m "v5.4.0 - Adaptive DJ 2.0"
git pull --rebase origin main
git push origin main
```

Ensuite :
1. vérifier que GitHub Pages a bien publié la nouvelle version ;
2. ouvrir Shuffle+ ;
3. aller dans **Réglages → Rechercher une mise à jour** ;
4. fermer complètement la PWA puis la relancer.
