SHUFFLE+ V9.2.0
================

1. Décompresser l’archive source dans le dépôt Git local.
2. Conserver le dossier caché .git du dépôt existant.
3. Ouvrir le dossier dans Visual Studio Code.
4. Exécuter : npm.cmd run validate
5. Exécuter : git add -A
6. Exécuter : git commit -m "Release Shuffle+ v9.2.0"
7. Exécuter : git push origin main

GitHub Pages publie le frontend.
Railway doit conserver Root Directory = /server.
