Shuffle+ v4.4.0 — Installation

1. Remplacer les fichiers du dépôt par le contenu du dossier ShufflePlus.
2. Publier :

   git add .
   git commit -m "v4.4.0 - Voice & Quick Control"
   git pull --rebase origin main
   git push origin main

3. Dans la PWA : Réglages → Rechercher une mise à jour.
4. En cas d’ancienne version persistante : fermer l’application, la rouvrir,
   puis utiliser le bouton de mise à jour. Le service worker v4.4 charge
   désormais les modules en network-first.

Sur iPhone, ouvre le menu ⚡ Rapide puis copie les URLs dans Raccourcis iOS.
