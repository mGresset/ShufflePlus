SHUFFLE+ V7.5.0 — INSTALLATION RAPIDE

1. Décompresser ShufflePlus-v7.5.0-patch.zip à la racine du dépôt v7.4.3.
2. Ouvrir le terminal Visual Studio Code.
3. Exécuter :

   git switch main
   git pull origin main
   git switch -c release/7.5.0
   npm run validate
   npm start

4. Tester http://127.0.0.1:5500/
5. Publier :

   git add .
   git commit -m "Release Shuffle+ v7.5.0"
   git push -u origin release/7.5.0

6. Créer puis fusionner la Pull Request vers main.
7. Fermer et rouvrir Shuffle+ sur l’iPhone.
