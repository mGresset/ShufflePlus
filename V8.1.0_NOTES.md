# Shuffle+ v8.1.0 — Synchronisation simplifiée

## Objectif

La synchronisation serveur était devenue difficile à comprendre à cause du nombre de catégories, des termes techniques et des choix entre envoi, réception et fusion.

La v8.1.0 remplace le parcours principal par une interface courte et guidée.

## Nouvelle page Synchronisation

L’écran principal affiche seulement :

- l’état de la connexion ;
- la date de la dernière synchronisation ;
- le bouton **Synchroniser maintenant** ;
- l’activation de la synchronisation automatique ;
- le nombre d’appareils liés.

Les identifiants techniques, paquets, transferts forcés et suppressions sont rangés dans **Options avancées**.

## Assistant serveur

Lorsqu’aucun serveur n’est configuré :

1. saisir l’adresse Railway ;
2. tester le serveur ;
3. créer une nouvelle sauvegarde ou rejoindre une sauvegarde existante avec un code `SP5...`.

La création d’un nouvel espace envoie automatiquement les données de l’appareil courant.

## Synchronisation en un clic

Le bouton **Synchroniser maintenant** :

1. conserve une sauvegarde locale annulable ;
2. compare les données locales et en ligne ;
3. récupère les changements distants ;
4. envoie les changements locaux ;
5. combine automatiquement les deux versions lorsqu’elles ont changé toutes les deux ;
6. affiche un résumé simple.

La combinaison automatique fusionne les catégories existantes sans supprimer volontairement les données locales. Elle est bloquée si la sauvegarde appartient à un autre compte Spotify.

## Gestion des différences

Si une décision reste nécessaire, trois choix sont affichés :

- **Combiner les deux — recommandé** ;
- **Conserver cet appareil** ;
- **Conserver la sauvegarde en ligne**.

La comparaison détaillée catégorie par catégorie reste accessible dans les options avancées.

## Données préservées

La mise à jour conserve la connexion Spotify, le Client ID, le serveur Railway, l’espace chiffré, les mix, les raccourcis, les thèmes, l’iPhone préféré et les réglages Dynamic Lyrics.
