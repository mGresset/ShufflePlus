# Shuffle+ v7.5.0 — Mes raccourcis

## Objectif

La v7.5.0 rend les profils de lancement iOS visibles et utilisables depuis une rubrique dédiée **Mes raccourcis**. Elle s’appuie sur les commandes iOS déjà enregistrées dans Shuffle+ : aucune recréation ni migration manuelle n’est nécessaire.

## Nouveautés

- rubrique **Mes raccourcis** dans le menu principal ;
- cartes de profils avec playlist ou mix, appareil cible, shuffle, départ, conduite et Dynamic Lyrics ;
- boutons **Lancer**, **Copier**, **Modifier**, **Dupliquer** et **Supprimer** ;
- état de préparation de chaque profil ;
- diagnostic du dernier lancement avec durée et étapes ;
- historique des dix derniers lancements ;
- assistant de création renvoyant vers le formulaire complet de Mix & iOS ;
- protection contre une double ouverture immédiate de la même URL iOS ;
- conservation des commandes rapides historiques dans un panneau secondaire.

## Diagnostic par profil

Pour les playlists fixes, Shuffle+ enregistre désormais :

1. validation de la configuration ;
2. détection de l’appareil Spotify ;
3. lancement et vérification de la lecture ;
4. ouverture éventuelle du mode conduite ;
5. demande éventuelle de Dynamic Lyrics ;
6. durée totale et message final.

## Compatibilité

- base : v7.4.3 ;
- aucune modification des scopes Spotify ;
- aucune suppression de données ;
- les commandes iOS existantes apparaissent automatiquement dans **Mes raccourcis** ;
- le cache PWA passe à `shuffleplus-v7.5.0`.
