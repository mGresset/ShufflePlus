# Shuffle+ v8.7.0 — Notes de version

## Objectif

La v8.7.0 renforce le parcours principal de Shuffle+ : lancer la bonne playlist depuis le raccourci Apple, sur le meilleur appareil Spotify disponible, avec une explication précise lorsqu’une étape échoue.

## Fiabilité du lancement

### Précontrôle

Avant d’envoyer une commande à Spotify, Shuffle+ vérifie désormais :

- la connexion Internet ;
- la présence du Client ID Spotify ;
- l’existence du profil principal ;
- la présence de la playlist ou du mix associé ;
- l’état connu de la session Spotify ;
- la présence éventuelle d’un appareil mémorisé.

Une configuration réellement bloquante arrête le lancement avant les appels Spotify inutiles.

### Dernier appareil opérationnel

L’appareil préféré et le dernier appareil opérationnel sont désormais deux informations distinctes.

Après une lecture confirmée, Shuffle+ enregistre l’appareil qui a réellement fonctionné. Lors du lancement suivant, cet appareil est prioritaire en mode « préféré », même lorsque Spotify lui attribue ensuite un nouveau `device_id` : le nom et le type permettent de le retrouver.

### Progression en six étapes

Le lancement affiche maintenant :

1. Profil et playlist
2. Connexion Spotify
3. Détection de l’appareil
4. Activation Spotify Connect
5. Envoi de la lecture
6. Vérification réelle

Chaque étape conserve son état, son message et son numéro de tentative dans le diagnostic.

### Récupération automatique

Lorsque Spotify accepte la commande mais ne confirme pas la lecture, Shuffle+ :

- transfère à nouveau la lecture vers l’appareil ;
- renvoie la playlist ;
- réapplique le shuffle ;
- vérifie une seconde fois l’appareil et la lecture.

## Erreurs actionnables

Les erreurs sont classées notamment comme :

- hors connexion ;
- session Spotify expirée ;
- quota ou limitation temporaire ;
- autorisation ou Spotify Premium insuffisant ;
- aucun appareil détecté ;
- lecture non confirmée ;
- profil incomplet.

L’écran propose ensuite une action principale adaptée : ouvrir Spotify, reconnecter le compte, modifier le profil ou réessayer.

Pour les problèmes récupérables provenant du raccourci Apple, la commande reste mémorisée afin de pouvoir être reprise après reconnexion ou activation de Spotify.

## Diagnostic

Le diagnostic copiable comprend maintenant :

- la version Shuffle+ ;
- l’état du réseau ;
- le profil et la source ;
- l’appareil tenté ;
- le dernier appareil opérationnel ;
- la durée totale ;
- les étapes et tentatives ;
- le code d’erreur ;
- l’action recommandée.

## Architecture

Nouveau module :

```text
core/launch-reliability.js
```

Il regroupe le précontrôle, la priorité des appareils, la classification des erreurs, les actions de récupération et la gestion pure des étapes. Il est préchargé par le Service Worker.

## Compatibilité

- aucune nouvelle variable Railway ;
- Client ID personnel conservé ;
- URL universelle Apple conservée ;
- profils existants conservés ;
- thèmes prédéfinis et couleur personnalisée conservés ;
- données locales existantes compatibles.
