Shuffle+ v7.1.1 — Installation et déploiement

1. Dans Spotify for Developers, ajouter exactement :
   https://mgresset.github.io/ShufflePlus/
   http://127.0.0.1:5500/

2. Remplacer les fichiers du dépôt par ceux de cette version en conservant le dossier .git du dépôt local.

3. Dans le terminal Visual Studio Code :
   npm test
   npm start

4. Tester sur :
   http://127.0.0.1:5500/

5. Dans GitHub, une seule fois :
   Settings > Pages > Source > GitHub Actions

6. Publier :
   git checkout main
   git pull origin main
   git add .
   git commit -m "Release Shuffle+ v7.1.1"
   git push origin main

7. Vérifier l’onglet Actions. Le workflow teste, construit puis publie automatiquement GitHub Pages.

8. Après validation :
   git tag -a v7.1.1 -m "Shuffle+ v7.1.1"
   git push origin v7.1.1

Guide détaillé : DEPLOIEMENT-V7.1.1.md
