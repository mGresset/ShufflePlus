# Shuffle+ v7.1.0 — Performance et hors connexion intelligent

## Démarrage plus rapide

Shuffle+ affiche immédiatement la dernière bibliothèque locale disponible,
puis vérifie Spotify en arrière-plan. Le badge d’état distingue :

- En ligne ;
- Synchronisation ;
- Données locales ;
- Hors connexion.

## Bibliothèque locale

Les métadonnées des playlists sont conservées dans le navigateur. Les
playlists et les morceaux aimés récemment ouverts peuvent également être
mémorisés dans IndexedDB et consultés sans réseau.

Le mode hors connexion reste volontairement en lecture seule : la lecture,
le transfert et les commandes Spotify nécessitent Internet.

## Économie de données

Le nouveau réglage évite les analyses Spotify automatiques et réutilise les
données locales tant qu’elles sont assez récentes. Les durées de conservation
sont configurables depuis Réglages → Performance et hors connexion.

## Cache PWA

Le service worker utilise désormais un cache d’interface séparé du cache
d’exécution, un démarrage hors connexion plus robuste et une stratégie
stale-while-revalidate pour les scripts et les styles.

## Sauvegarde

Les préférences de performance sont incluses dans la sauvegarde Shuffle+.
Les contenus Spotify mis en cache restent propres à chaque navigateur.
