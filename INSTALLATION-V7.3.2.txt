SHUFFLE+ v7.3.2 — INSTALLATION RAPIDE

1. Extraire ShufflePlus-v7.3.2-patch.zip à la racine du dépôt v7.3.1.
2. Autoriser le remplacement des fichiers.
3. Facultatif : supprimer startup-recovery-7.3.1.js.
4. Lancer : npm run validate
5. Lancer : npm start
6. Tester sur http://127.0.0.1:5500/
7. Publier la branche hotfix/7.3.2 puis la fusionner dans main.
8. Sur iPhone, fermer complètement la PWA et la rouvrir.
