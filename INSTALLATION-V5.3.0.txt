Shuffle+ v5.3.0 — Installation

1. Sauvegarder le dossier actuellement publié.
2. Remplacer tous les fichiers client par ceux du ZIP.
3. Le dossier server peut rester identique.
4. Publier :

   git add .
   git commit -m "v5.3.0 - Interface dynamique et thèmes"
   git pull --rebase origin main
   git push origin main

5. Dans Shuffle+ :
   Réglages → Rechercher une mise à jour.

6. Fermer complètement la PWA puis la relancer.

La couleur par défaut est Violet. Elle peut être modifiée dans :
Réglages → Apparence.
