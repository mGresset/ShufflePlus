# Shuffle+ v6.4.2 — Correctif du menu PC

## Correction principale

Sur ordinateur, les intitulés du menu restent désormais sur une seule ligne :

- Accueil ;
- Ma musique ;
- Mix & iOS ;
- Adaptive DJ ;
- Assistant ;
- Pour toi ;
- Statistiques ;
- Intelligence ;
- Rapide ;
- Conduite ;
- Réglages.

Les mots ne sont plus coupés. Lorsque la largeur disponible est insuffisante, la barre défile horizontalement au lieu de passer les intitulés sur plusieurs lignes.

- tri par défaut « Modifiées récemment » ;
