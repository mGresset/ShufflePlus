# Shuffle+ v8.3.0

## Objectif

Transformer l’ancienne rubrique de raccourcis en un véritable centre de lancement, sans casser les profils existants ni la chaîne de déploiement GitHub vers Railway.

## Centre de lancement

La navigation principale affiche désormais **Lancer**. L’identifiant interne `quick` est volontairement conservé afin que les anciens liens, réglages et sauvegardes restent valides.

Le centre affiche :

- le profil principal ;
- la playlist ou le mix ciblé ;
- l’appareil attendu ;
- l’état du shuffle et du mode conduite ;
- un bouton de lancement principal ;
- le dernier diagnostic détaillé ;
- les profils secondaires existants.

## Raccourci Apple universel

Une nouvelle URL stable utilise l’action `launch`. Elle ne contient pas l’identifiant d’un profil précis : au moment de l’ouverture, Shuffle+ résout le profil principal enregistré.

Conséquence : un seul raccourci Apple peut rester installé tandis que l’utilisateur change de playlist principale depuis Shuffle+.

Le partage natif est proposé sur les appareils compatibles. La copie dans le presse-papiers reste disponible en secours.

## Lancement guidé

Le lancement d’une playlist fixe affiche successivement :

1. validation du profil ;
2. recherche de l’appareil Spotify ;
3. démarrage et vérification de la lecture.

En cas d’échec, l’écran propose directement :

- d’ouvrir Spotify ;
- de changer d’appareil ou de profil ;
- de reconnecter Spotify ;
- de réessayer ;
- de copier le diagnostic complet.

## Installation simplifiée

La checklist interne conserve ses sept contrôles pour la compatibilité avec les sauvegardes v8.2. L’interface n’affiche toutefois qu’une seule prochaine étape, avec la liste complète repliée dans un panneau secondaire.

## Mode conduite

Le mode conduite charge désormais la file Spotify dès son ouverture et affiche les trois prochains titres sous le morceau actif. La liste complète reste accessible avec le bouton dédié.

## Thèmes

Aucun thème n’a été supprimé. Les couleurs prédéfinies, les couleurs personnalisées, le contraste automatique, la réduction des mouvements et la synchronisation des préférences restent actifs. Les nouveaux composants utilisent les mêmes variables CSS de thème.

## Compatibilité

- mise à jour directe depuis la v8.2.0 ;
- aucune migration des profils iOS ;
- aucune modification du Client ID Spotify ;
- aucune modification du contrat de synchronisation Railway ;
- anciennes URLs de profils toujours fonctionnelles ;
- modes Essentiel et Expert conservés.
