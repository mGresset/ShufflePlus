Shuffle+ v6.3.0 — Installation

1. Sauvegarder le dossier actuellement publié.
2. Remplacer les fichiers du dépôt par ceux du ZIP.
3. Publier :

   git add .
   git commit -m "v6.3.0 - Statistiques ecoute avancees"
   git pull --rebase origin main
   git push origin main

4. Attendre la publication GitHub Pages.
5. Ouvrir Shuffle+ puis Réglages → Rechercher une mise à jour.
6. Fermer complètement la PWA et la relancer.

Le nouvel onglet s’appelle « Statistiques ».
