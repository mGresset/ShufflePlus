Shuffle+ v4.9.0 — Installation

1. Remplacer tous les fichiers du dépôt par ceux du ZIP.
2. Publier :

   git add .
   git commit -m "v4.9.0 - Detailed diff and encrypted transfer"
   git pull --rebase origin main
   git push origin main

3. Dans la PWA : Réglages → Rechercher une mise à jour.
4. En cas d’ancien cache persistant : fermer complètement la PWA puis la rouvrir.

Test conseillé : exporter un paquet chiffré, l’analyser avec le bon mot de passe, puis vérifier l’aperçu détaillé sans appliquer la fusion.
