# Shuffle+ v8.3.2 — Notes de version

## Objectif

Cette version corrige les régressions visuelles observées après la mise en place du design system v8.3.1, sans modifier le fonctionnement Spotify ni les données utilisateur.

## Correctifs du header

- ajout d’une règle globale `[hidden] { display: none !important; }` ;
- correction du bouton « Se connecter à Spotify » qui pouvait rester visible alors que la session était déjà connectée ;
- grille desktop stabilisée en quatre zones : marque, version/statut, bienvenue et actions ;
- largeur des boutons calculée selon leur contenu ;
- suppression des retours à la ligne involontaires sur « Se déconnecter » et « Installer l’application » ;
- adaptation intermédiaire entre 761 et 1100 px avec une seconde ligne d’actions ;
- comportement mobile historique conservé.

## Navigation

- position sticky ramenée à `top: 0` sur ordinateur ;
- suppression de la bande laissant apparaître le contenu derrière la navigation ;
- fond et ombre renforcés pour conserver la séparation visuelle pendant le défilement.

## Réglages

Toutes les rubriques de la page Réglages suivent désormais le thème actif :

- Priorités intelligentes ;
- Transitions intelligentes ;
- Courbe d’intensité ;
- Exclusions ;
- Nettoyage ;
- sauvegarde, PWA, Spotify, synchronisation et diagnostic.

Les anciens accents spécifiques aux modules sont remplacés par une hiérarchie commune :

- Enregistrer / appliquer : couleur principale du thème ;
- Réinitialiser : bouton neutre ;
- suppression réelle : rouge sémantique ;
- champs, cases et sliders : couleur du thème ;
- cartes et conteneurs : surfaces communes du design system.

## Compatibilité

- aucune migration de stockage ;
- aucun changement d’API ;
- aucune nouvelle variable Railway ;
- profils de lancement et raccourcis Apple conservés ;
- thèmes prédéfinis et couleur personnalisée conservés.
