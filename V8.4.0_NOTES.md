# Shuffle+ v8.4.0 — Notes de version

## Objectif

La v8.4.0 consolide l’identité visuelle de Shuffle+ sur toutes les rubriques et améliore le mode conduite, sans modifier les données utilisateur, l’authentification Spotify ni le déploiement Railway.

## Design global

- ajout du module `core/ui-consistency.js` ;
- détection des actions principales, secondaires, discrètes et dangereuses ;
- application automatique après chaque rendu dynamique ;
- exclusion des composants structurels spécialisés, comme les cartes de playlist, les onglets et les commandes de conduite ;
- palette active appliquée aux anciens boutons principaux ;
- formulaires harmonisés dans toutes les pages, et plus seulement dans Réglages ;
- couleurs rouge, jaune et verte réservées aux véritables états sémantiques ;
- treize thèmes prédéfinis et couleur personnalisée intégralement conservés.

## Mode conduite

- progression du titre avec temps écoulé et temps restant ;
- aperçu de la file toujours présent ;
- bouton permettant de charger la file lorsqu’elle est encore vide ;
- état « À charger », « À jour » ou « À actualiser » ;
- trois prochains titres avec pochette, artiste et durée ;
- panneau complet de file enrichi avec son état de fraîcheur ;
- lien direct vers le morceau actif dans Spotify ;
- disposition mobile compacte, avec adaptation spécifique aux écrans courts et au paysage.

## Architecture

Deux responsabilités sont désormais extraites d’`app.js` :

- `core/ui-consistency.js` pour la sémantique des composants ;
- `core/driving-ui.js` pour la progression, la fraîcheur et le modèle d’aperçu de la file.

Ces modules sont préchargés par le Service Worker et couverts par des tests unitaires.

## Compatibilité

- aucune migration de stockage ;
- aucune nouvelle variable Railway ;
- profils et raccourcis Apple conservés ;
- serveur de synchronisation inchangé ;
- cache PWA renouvelé en `shuffleplus-v8.4.0`.
