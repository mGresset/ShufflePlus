SHUFFLE+ V7.8.0 — INSTALLATION RAPIDE

BASE REQUISE
- Shuffle+ v7.7.0 stable.

1. Décompresser ShufflePlus-v7.8.0-patch.zip dans le dépôt v7.7.0.
2. Facultatif : Remove-Item .\startup-recovery-7.7.0.js -ErrorAction SilentlyContinue
3. Exécuter : npm run validate
4. Exécuter : npm start
5. Tester : http://127.0.0.1:5500/
6. Tester iOS : http://127.0.0.1:5500/?debug_ios=1
7. Vérifier les cinq menus : Accueil, Musique, Créer, Raccourcis, Réglages.
8. Vérifier les sous-menus Voir plus.
9. Publier la branche release/7.8.0 puis fusionner la Pull Request.

MISE À JOUR PWA
- Un seul clic sur Mettre à jour.
- Le bouton affiche Mise à jour… pendant l’activation.
- Le bandeau ne doit pas revenir pour la même version après le rechargement.

AUCUNE DONNÉE SUPPRIMÉE
- Client ID et connexion Spotify conservés.
- Mix, profils, raccourcis et iPhone préféré conservés.
- Réglages, statistiques et cache hors connexion conservés.
