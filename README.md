# Shuffle+ v8.3.1

Shuffle+ lance des playlists Spotify, crée des mélanges intelligents et prépare des raccourcis Apple avec un Client ID Spotify personnel.

## v8.3.1 — Interface unifiée et thèmes globaux

- nouveau fichier `design-system.css`, chargé après les styles historiques ;
- boutons harmonisés en quatre variantes : principale, secondaire, discrète et danger ;
- mêmes hauteurs, arrondis, bordures, espacements et états de survol ;
- formulaires uniformisés : champs, listes, zones de texte, focus et options ;
- correction des composants récents qui utilisaient `--accent-color` sans liaison avec le thème actif ;
- alias de compatibilité entre toutes les générations de variables CSS ;
- couleur personnalisée appliquée aux boutons, formulaires, cartes, focus et états actifs ;
- modes contraste renforcé et réduction des animations conservés ;
- accueil, lancement principal et centre de lancement alignés sur le même langage visuel ;
- PWA, profils, raccourcis Apple, synchronisation et déploiement GitHub → Railway inchangés.

Les treize palettes prédéfinies et la couleur personnalisée restent disponibles.

Voir `V8.3.1_NOTES.md` et `DEPLOIEMENT-V8.3.1.md`.
