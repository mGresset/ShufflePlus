# Shuffle+ v7.7.0 — Mélange intelligent explicable

## Objectif

Rendre le moteur Shuffle+ compréhensible, vérifiable et reproductible sans supprimer les réglages, profils, raccourcis ou données de la v7.6.0.

## Nouveautés

- graine unique attribuée à chaque nouveau mélange ;
- bouton **Copier** pour conserver ou partager la graine ;
- bouton **Rejouer exactement** pour recréer le même ordre ;
- comparaison avant/après sur les artistes, albums, transitions, titres récents et courbe d’intensité ;
- score global de qualité avant et après le mélange ;
- indication des contraintes relâchées lorsque la bibliothèque ne permet pas de tout respecter ;
- explication des quinze premiers placements dans le rapport ;
- accès **Pourquoi ici ?** directement sous chaque morceau tant qu’il reste à la position choisie par le moteur ;
- choix progressif des candidats : contraintes strictes, puis relâchement contrôlé faute d’alternative ;
- générateur pseudo-aléatoire déterministe compatible avec les mélanges existants.

## Reproductibilité

La graine, l’ordre des sources et l’historique récent pris en compte sont conservés dans le rapport courant. Le bouton **Rejouer exactement** réutilise ces éléments afin d’obtenir le même résultat dans la session.

## Compatibilité

La fonction historique `smartShuffleTracks()` reste disponible pour les autres modules. Elle utilise le nouveau moteur sans modifier les appels existants.

## Données

Aucune migration de stockage n’est nécessaire. La mise à jour conserve :

- le Client ID Spotify personnel ;
- les tokens Spotify ;
- les mix et profils ;
- les raccourcis iOS ;
- l’iPhone préféré ;
- les réglages de conduite ;
- les statistiques, objectifs et données hors connexion.
