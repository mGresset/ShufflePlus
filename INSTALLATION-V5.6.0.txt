Shuffle+ v5.6.0 — Installation

1. Remplacer les fichiers de votre dépôt par ceux de l’archive.
2. Publier :

   git add .
   git commit -m "v5.6.0 - Planificateur intelligent"
   git pull --rebase origin main
   git push origin main

3. Dans la PWA : Réglages → Rechercher une mise à jour.
4. Fermer puis rouvrir complètement Shuffle+.

Le serveur Node.js ne nécessite pas de redéploiement.
