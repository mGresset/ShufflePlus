SHUFFLE+ 8.3.2 — INSTALLATION DEPUIS 8.3.1

1. Créer la branche :
   git switch main
   git pull origin main
   git switch -c release/8.3.2

2. Extraire le patch à la racine du dépôt.

3. Valider :
   npm run validate
   npm start

4. Pousser :
   git add .
   git commit -m "Release Shuffle+ v8.3.2"
   git push -u origin release/8.3.2

5. Fusionner directement :
   git switch main
   git pull origin main
   git merge release/8.3.2
   git push origin main

6. Après validation Railway :
   git branch -d release/8.3.2
   git push origin --delete release/8.3.2
