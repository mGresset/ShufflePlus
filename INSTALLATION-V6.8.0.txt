Shuffle+ v6.8.0 — Installation

1. Sauvegarder le dossier publié.
2. Remplacer les fichiers par ceux du ZIP.
3. Publier :

   git add .
   git commit -m "v6.8.0 - Recherche universelle"
   git pull --rebase origin main
   git push origin main

4. Attendre GitHub Pages.
5. Ouvrir Réglages → Rechercher une mise à jour.
6. Fermer complètement Safari ou la PWA, puis relancer Shuffle+.

La recherche est accessible au-dessus du menu ou avec Ctrl/⌘ + K.
