Shuffle+ v6.2.0 — Installation

1. Remplacer les fichiers du dépôt par ceux du ZIP.
2. Publier :

   git add .
   git commit -m "v6.2.0 - Recommandations personnalisees"
   git pull --rebase origin main
   git push origin main

3. Attendre GitHub Pages.
4. Dans Shuffle+ : Réglages → Rechercher une mise à jour.
5. Fermer complètement la PWA puis la relancer.

Le nouvel onglet s’appelle « Pour toi ».
