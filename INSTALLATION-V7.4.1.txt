SHUFFLE+ v7.4.1 — INSTALLATION RAPIDE

1. Décompresser ShufflePlus-v7.4.1-patch.zip à la racine du dépôt v7.4.0.
2. Dans Visual Studio Code :

   git switch main
   git pull origin main
   git switch -c hotfix/7.4.1
   git add --renormalize .
   npm run validate

3. Publier :

   git add .
   git commit -m "Hotfix Shuffle+ v7.4.1"
   git push -u origin hotfix/7.4.1

4. Créer et fusionner la Pull Request.

La commande git add --renormalize . applique la politique de fins de ligne du nouveau fichier .gitattributes.
