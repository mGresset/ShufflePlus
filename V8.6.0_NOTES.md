# Shuffle+ 8.6.0 — Palette cohérente dans les réglages

## Objectif

Cette version corrige les surfaces vertes qui pouvaient encore apparaître dans la rubrique **Application installable**, même lorsque le thème actif était bleu, violet ou personnalisé.

## Cause corrigée

Une ancienne règle CSS ciblait tous les éléments `span` placés dans `.pwa-capabilities`. Elle s’appliquait aussi au libellé interne de chaque capacité et lui imposait un fond vert historique.

La règle cible désormais uniquement les cartes directes :

```css
.pwa-capabilities > .pwa-capability
```

Les libellés internes sont explicitement remis à zéro afin qu’ils héritent de la couleur de la carte et du thème.

## Changements visibles

- suppression du fond vert derrière **Cache de l’interface** ;
- suppression du fond vert derrière **Ressources hors connexion** ;
- suppression du fond vert derrière **Mode application** ;
- badge d’installation, bordures, panneaux et boutons liés à la PWA pilotés par le thème actif ;
- thème bleu : surfaces bleues ;
- thème violet : surfaces violettes ;
- couleur personnalisée : surfaces dérivées de cette couleur ;
- rouge conservé uniquement pour une capacité réellement indisponible.

## Protection contre les régressions

Un nouveau test `tests/v860-settings-theme.test.mjs` vérifie :

- que l’ancien sélecteur générique n’existe plus ;
- que les libellés internes restent transparents ;
- que la zone PWA ne contient plus les anciennes couleurs vertes fixes ;
- que les états prêts et informatifs utilisent `--accent` et `--accent-rgb` ;
- que le preset bleu reste bien `#3b82f6` / `#06b6d4`.

## Compatibilité

- profils Spotify conservés ;
- raccourcis Apple conservés ;
- thèmes et couleur personnalisée conservés ;
- synchronisation conservée ;
- déploiement GitHub → Railway inchangé ;
- aucune nouvelle variable Railway.
