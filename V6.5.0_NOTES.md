# Shuffle+ v6.5.0 — Objectifs & bilan hebdomadaire

## Nouvel onglet « Objectifs »

Cette version ajoute un suivi hebdomadaire local basé sur les événements déjà enregistrés par Shuffle+ :

- nombre de sessions ;
- jours actifs ;
- nouveaux mix ou nouvelles scènes découverts ;
- écoutes confirmées ;
- titres observés et durée potentielle ;
- comparaison avec la semaine précédente.

## Badges

Six badges sont calculés automatiquement : Première impulsion, En rythme, Régulier, Explorateur, Écoute vérifiée et Champion de la semaine.

## Personnalisation

Les quatre objectifs peuvent être modifiés. La semaine se recalcule automatiquement chaque lundi. Un export JSON du bilan est disponible.

## Assistant vocal

Nouvelle commande : « Montre mes objectifs musicaux ».

## Synchronisation

Les objectifs sont inclus dans les sauvegardes et la synchronisation complète. Le serveur Node.js reste inchangé.
