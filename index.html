Première configuration

Connecter votre application Spotify

Chaque utilisateur de Shuffle+ utilise son propre Client ID Spotify Developer. Aucun Client Secret n’est demandé.

  1. Créez une application dans Spotify for Developers.
  2. Activez la Web API.
  3. Ajoutez exactement l’adresse de redirection ci-dessous.
  4. Copiez le Client ID de votre application.
Adresse de redirection
Le Client ID est enregistré uniquement dans ce navigateur. Les commandes de lecture nécessitent un compte Spotify compatible.

Réparer Shuffle+

Commence par réparer le cache. Cette opération conserve tes réglages, tes mix et ta connexion Spotify.

La réinitialisation Spotify ne supprime ni tes playlists, ni ton appareil préféré, ni tes autres réglages.
Une mise à jour de Shuffle+ est prête. Recharge l’application pour l’activer.
