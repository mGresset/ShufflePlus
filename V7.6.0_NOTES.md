# Shuffle+ v7.6.0 — Accès public et expérience iOS

## Objectif

Permettre à plusieurs personnes d’utiliser le même site Shuffle+ avec leur propre application Spotify Developer, tout en réservant l’interface Conduite aux iPhone et iPad.

## Nouveautés

- assistant de première configuration Spotify ;
- saisie locale d’un Client ID personnel ;
- aucun Client Secret demandé ;
- migration automatique du Client ID historique pour les installations déjà connectées ;
- panneau Connexion Spotify dans Réglages ;
- changement, test et réinitialisation du Client ID ;
- conservation des mix, raccourcis, statistiques et préférences lors d’un changement de Client ID ;
- mode Conduite masqué sur PC, Mac de bureau et Android ;
- anciennes URL `?view=driving` redirigées vers l’accueil hors iOS ;
- option Conduite masquée dans les profils hors iOS ;
- simulation locale avec `?debug_ios=1`, impossible sur le site public.

## Migration

Une installation v7.5.0 déjà authentifiée récupère automatiquement le Client ID historique dans le nouveau stockage local. Un nouvel utilisateur ne reçoit aucun Client ID partagé et doit saisir le sien.

## Stockage

Le Client ID est enregistré sous la clé locale `shuffleplus_spotify_app_config_v1`. Il n’est pas inclus dans les jetons, et aucun Client Secret n’est stocké.
