Shuffle+ v5.1.1 — Installation

1. Sauvegarder le dossier actuellement publié.
2. Remplacer tous les fichiers client par ceux de ce ZIP.
3. Le dossier server peut rester identique : aucune modification serveur n’est requise.
4. Publier :

   git add .
   git commit -m "v5.1.1 - Correctif iPhone et toast de copie"
   git pull --rebase origin main
   git push origin main

5. Dans la PWA :
   Réglages → Rechercher une mise à jour.

En cas d’ancien affichage persistant :
- fermer complètement Shuffle+ ;
- rouvrir l’application ;
- en dernier recours, supprimer puis réinstaller la PWA.
