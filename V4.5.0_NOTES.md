# Shuffle+ v4.5.0 — Contextes et profils rapides

## Nouveautés

- quatre profils rapides personnalisables : Trajet, Travail, Soirée et Nuit ;
- association d’un mix enregistré et d’un profil de réglages à chaque contexte ;
- lancement ou simple préparation selon le réglage choisi ;
- commandes vocales reliées en priorité aux profils configurés ;
- URL dédiée `?action=quick-context&context=...` ;
- assistant guidé pour créer les raccourcis iOS ;
- retour visuel après une commande lancée depuis une URL externe ;
- sauvegarde/restauration JSON des profils rapides ;
- raccourcis PWA Trajet et Travail ;
- aucun nouveau module JavaScript.

## Première configuration

Ouvrir **Rapide → Configurer les profils rapides**, associer un mix à chaque contexte utile, puis enregistrer. Le bouton reste désactivé tant qu’aucun mix n’est associé.
