# Shuffle+ v6.3.0 — Statistiques d’écoute avancées

## Nouvel onglet « Statistiques »

Cette version ajoute un tableau de bord séparé de l’onglet Intelligence :

- sessions envoyées à Spotify ;
- écoutes confirmées manuellement ;
- durée potentielle et durée confirmée ;
- titres et moyenne par session ;
- jours actifs et série observée ;
- taux de confirmation ;
- activité quotidienne sur 7 ou 14 jours ;
- répartition Matin / Journée / Soirée / Nuit ;
- comparaison des jours de la semaine ;
- top mix, artistes et albums ;
- origine des lancements : manuel, Adaptive DJ, planificateur ou iOS.

## Filtres et export

- périodes : 7 jours, 30 jours, 90 jours, 12 mois ou toutes les données ;
- vue principale : lancements envoyés ou écoutes confirmées ;
- export CSV détaillé ;
- export JSON avec métriques, classements et événements.

## Transparence

Shuffle+ ne transforme pas automatiquement une file envoyée à Spotify en temps d’écoute réel. Le tableau distingue clairement :

- la durée potentielle des titres envoyés ;
- la durée confirmée manuellement.

## Assistant musical et vocal

La commande « Montre mes statistiques d’écoute » ouvre directement le nouvel onglet.

## Compatibilité

- aucune nouvelle autorisation Spotify ;
- serveur Node.js inchangé ;
- réglages inclus dans la sauvegarde et la synchronisation complète.
