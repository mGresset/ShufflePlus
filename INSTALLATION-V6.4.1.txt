Shuffle+ v6.4.1 — Installation

1. Remplacer les fichiers du dépôt par ceux du ZIP.
2. Publier :

   git add .
   git commit -m "v6.4.1 - Correctif navigation iOS et tri"
   git pull --rebase origin main
   git push origin main

3. Dans la PWA : Réglages → Rechercher une mise à jour.
4. Appuyer sur Mettre à jour.
5. Fermer complètement Shuffle+ depuis le sélecteur d’apps iOS.
6. Relancer la PWA et vérifier que la version affichée est 6.4.1.

Le premier affichage « Modifiées récemment » peut prendre quelques secondes,
car Shuffle+ analyse la date du dernier ajout de chaque playlist.
