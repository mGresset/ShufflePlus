# Shuffle+ v7.4.2 — Notes de version

## Correction

Le test « le contrôle OAuth accepte les fins de ligne LF et CRLF » normalise maintenant `auth.js` avant de fabriquer ses deux variantes de test.

Dans la v7.4.1, un fichier déjà enregistré en `CRLF` pouvait être transformé en `\r\r\n` par la simulation, ce qui faisait échouer le test alors que le code OAuth était correct.

## Impact

- aucune modification de la connexion Spotify ;
- aucune modification de Dynamic Lyrics ;
- aucune migration de données ;
- cache PWA renouvelé en v7.4.2 ;
- déploiement Windows et GitHub Actions fiabilisé.
