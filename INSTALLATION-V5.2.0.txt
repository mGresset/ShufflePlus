Shuffle+ v5.2.0 — Installation

1. Sauvegarder le dossier actuellement publié.
2. Remplacer les fichiers client par ceux du ZIP.
3. Le dossier server peut rester identique.
4. Publier :

   git add .
   git commit -m "v5.2.0 - Mix Studio avance"
   git pull --rebase origin main
   git push origin main

5. Dans la PWA : Réglages → Rechercher une mise à jour.
6. Fermer complètement Shuffle+ puis relancer si l’ancienne interface reste visible.
