# Shuffle+ v5.3.0 — Dynamique & Musicale

## Direction visuelle

Cette version conserve toutes les fonctions de Shuffle+ v5.2,
mais adopte une interface inspirée des applications musicales :

- fond sombre bleu-noir ;
- cartes immersives et légèrement vitrées ;
- violet comme couleur d’accent par défaut ;
- dégradés plus subtils et moins flashy ;
- en-tête compact après connexion ;
- navigation mobile fixe en bas de l’écran ;
- mise en valeur d’Adaptive DJ, Mix Studio et Intelligence.

## Personnalisation

Dans Réglages → Apparence :

- Violet ;
- Bleu ;
- Rose ;
- Émeraude ;
- Orange ;
- activation ou réduction des animations.

La couleur est appliquée immédiatement, enregistrée localement,
incluse dans les sauvegardes JSON et synchronisée avec le serveur v5.

## Compatibilité

- correctif iPhone v5.1.1 conservé ;
- Mix Studio avancé v5.2 conservé ;
- serveur Node.js inchangé ;
- aucune modification des autorisations Spotify.
