# Shuffle+ v7.4.1 — Notes de version

## Correctif principal

La validation `npm` pouvait échouer sous Windows avec un message semblable à :

```text
expected: /clearTemporaryAuth\(\);\n\s*console\.error\("Erreur token Spotify/
```

Le code OAuth était correct. Le test supposait toutefois une fin de ligne Unix `LF`, alors qu’un fichier enregistré sous Windows peut utiliser `CRLF`.

## Modifications

- le test OAuth accepte `LF` et `CRLF` ;
- ajout de `.gitattributes` pour normaliser les fichiers texte en `LF` dans Git ;
- nouveau test simulant explicitement un fichier `CRLF` ;
- le build ne publie que le fichier `startup-recovery` de la version courante ;
- passage du cache PWA et des ressources à la version 7.4.1 ;
- aucune modification du fonctionnement Spotify, Dynamic Lyrics, du mode conduite ou des données locales.
