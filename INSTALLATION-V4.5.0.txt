Shuffle+ v4.5.0 — Installation

1. Remplacer les fichiers du projet par ceux de cette archive.
2. Publier :

   git add .
   git commit -m "v4.5.0 - Contextes et profils rapides"
   git pull --rebase origin main
   git push origin main

3. Dans la PWA : Réglages → Rechercher une mise à jour.
4. Ouvrir Rapide et configurer les quatre profils.
