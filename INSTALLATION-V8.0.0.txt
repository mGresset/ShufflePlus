SHUFFLE+ V8.0.0 — INSTALLATION RAPIDE

Base requise : Shuffle+ v7.9.0

1. Exporter une sauvegarde Shuffle+.
2. Décompresser ShufflePlus-v8.0.0-patch.zip à la racine du dépôt.
3. Supprimer l’ancien fichier :
   Remove-Item .\startup-recovery-7.9.0.js -ErrorAction SilentlyContinue
4. Exécuter :
   git switch main
   git pull origin main
   git switch -c release/8.0.0
   npm run validate
   npm start
5. Tester http://127.0.0.1:5500/
6. Publier :
   git add .
   git commit -m "Release Shuffle+ v8.0.0"
   git push -u origin release/8.0.0
7. Créer et fusionner la Pull Request.
8. Fermer puis rouvrir la PWA iPhone après le déploiement.

Une installation existante passe automatiquement en mode Expert.
Une nouvelle installation démarre en mode Essentiel.
