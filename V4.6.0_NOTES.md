# Shuffle+ v4.6.0 — Préparation à la synchronisation

## Nouveautés

- identifiant local unique pour chaque installation ;
- nom personnalisable de l’appareil ;
- aperçu des données synchronisables ;
- empreinte locale et taille estimée du paquet ;
- export d’un paquet de synchronisation versionné ;
- analyse d’un paquet provenant d’un autre appareil ;
- comparaison des résumés et détection des différences ;
- résolution manuelle ou selon une politique choisie ;
- export d’un diagnostic sans jeton Spotify ;
- contrat d’API documenté pour la future v5.

## Important

Aucune donnée n’est envoyée sur Internet par cette version. Le serveur n’existe pas encore : la synchronisation est simulée par export/import de paquets JSON.
