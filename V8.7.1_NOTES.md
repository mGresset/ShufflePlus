# Shuffle+ v8.7.1 — Recherche compacte dans le menu

## Objectif

Réduire l’encombrement du haut des pages sans perdre la recherche universelle de Shuffle+.

## Changements principaux

### Recherche intégrée à la navigation

La grande carte « Rechercher dans Shuffle+ » a été retirée. Une nouvelle action **Rechercher** est placée directement dans la barre principale, à côté de Réglages.

- ordinateur : icône, libellé et rappel du raccourci clavier ;
- tablette : icône et libellé ;
- mobile/PWA : icône seule pour préserver l’espace.

Le bouton est accessible avec `Ctrl + K` sur Windows/Linux et `⌘ + K` sur macOS. La touche `/` continue également d’ouvrir la recherche lorsqu’aucun champ n’est actif.

### Palette plus compacte

La fenêtre de recherche est moins large et sa hiérarchie est simplifiée. Les commandes restent disponibles :

- flèches haut/bas pour naviguer ;
- Entrée pour ouvrir ;
- Échap pour fermer ;
- effacement de la requête et de l’historique ;
- clic extérieur pour fermer.

### Résultats regroupés

Les résultats sont désormais regroupés selon leur nature :

- rubriques et réglages ;
- playlists ;
- mix ;
- scènes ;
- profils ;
- routines et raccourcis.

Le classement de pertinence et l’index clavier sont conservés à l’intérieur de ces groupes.

### Bibliothèque

Le filtre local « Nom de playlist ou propriétaire » reste disponible dans la rubrique Musique. Il ne se confond plus avec la recherche globale de toute l’application.

## Compatibilité

- aucune migration de données ;
- aucun changement des profils ou raccourcis Apple ;
- thèmes et couleur personnalisée conservés ;
- aucune nouvelle variable Railway ;
- chaîne VS Code → GitHub → Railway inchangée.
