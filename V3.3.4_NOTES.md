# Shuffle+ v3.3.4 — Adaptive DJ Menu Edition

## Changements visibles
- navigation par menus au lieu d’une longue pile de blocs ;
- onglets Ma musique, Mix & iOS, Adaptive DJ et Réglages ;
- configuration des cinq créneaux Adaptive DJ ;
- association de chaque créneau à un mix enregistré ;
- bouton Lancer maintenant ;
- simulation d’un créneau sans lancer Spotify ;
- URL iOS universelle `?action=adaptive&autoplay=1` ;
- historique Adaptive DJ ;
- sauvegarde/restauration JSON des réglages Adaptive DJ.

## Architecture
`adaptive-dashboard.js` et `adaptive-config.js` ont été retirés.
Adaptive DJ est piloté depuis `app.js` et conserve seulement
`adaptive-dj.js` pour la définition des créneaux horaires.
