Shuffle+ v7.1.0 — Installation

1. Sauvegarder le dépôt publié.
2. Remplacer son contenu par les fichiers du ZIP.
3. Publier :

   git add .
   git commit -m "v7.1.0 - Performance et hors connexion"
   git pull --rebase origin main
   git push origin main

4. Dans Shuffle+ : Réglages → Rechercher une mise à jour.
5. Fermer complètement Safari ou la PWA puis la relancer.
6. Ouvrir une playlist une première fois pour la rendre consultable hors connexion.
