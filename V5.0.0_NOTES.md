# Shuffle+ v5.0.0 — Serveur & synchronisation automatique

## Fonctionnalités

- serveur Node.js réellement exécutable, sans dépendance externe ;
- espaces privés multi-appareils ;
- codes de liaison SP5 ;
- jeton distinct et révocable pour chaque installation ;
- chiffrement AES-GCM de bout en bout avant chaque envoi ;
- révisions optimistes et détection des conflits ;
- envoi/réception manuels ;
- synchronisation automatique de 1 à 60 minutes lorsque la PWA est ouverte ;
- application automatique uniquement lorsque les données locales n’ont pas changé ;
- fusion sélective v4.8/v4.9 conservée lorsque deux appareils ont modifié les données ;
- liste et révocation des appareils ;
- suppression complète de l’espace distant ;
- Dockerfile, compose, test d’intégration et documentation de déploiement.

## Limites

- le serveur doit être hébergé séparément de GitHub Pages ;
- la PWA ne peut pas synchroniser lorsqu’iOS l’a totalement suspendue ;
- le code SP5 doit rester secret ;
- la persistance dépend du disque configuré sur l’hébergement.
