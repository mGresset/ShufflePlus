# Shuffle+ v8.0.0 — Version publique simplifiée

Shuffle+ 8 transforme la version 7.9 en une application plus facile à découvrir, sans supprimer les fonctions historiques.

## Mode Essentiel et mode Expert

- Une nouvelle installation démarre en **mode Essentiel**.
- Une installation provenant d’une ancienne version est automatiquement placée en **mode Expert** afin de conserver tous ses accès.
- Le mode peut être changé à tout moment dans `Réglages → Expérience Shuffle+ 8`.
- Les fonctions masquées en mode Essentiel ne sont ni effacées ni réinitialisées.

Le mode Essentiel conserve notamment :

- Accueil ;
- Ma musique et Pour toi ;
- Raccourcis iOS et Assistant ;
- Mes raccourcis ;
- Mode conduite sur iPhone/iPad ;
- Réglages principaux et Guide.

Le mode Expert réaffiche les statistiques, objectifs, analyses, Adaptive DJ, modes d’utilisation, diagnostics et réglages fins du moteur.

## Accueil Shuffle+ 8

Un nouveau bandeau d’accueil met en avant les trois usages principaux :

1. lancer un raccourci iPhone ;
2. retrouver sa musique ;
3. créer un mix.

Les accès rapides du tableau de bord s’adaptent au mode Essentiel ou Expert.

## Première configuration publique

L’écran de première configuration explique plus clairement :

- l’objectif de Shuffle+ ;
- la création d’une application Spotify Developer ;
- l’adresse de redirection à copier ;
- la saisie du Client ID personnel ;
- l’absence totale de Client Secret dans Shuffle+.

## Synchronisation Railway sécurisée

Shuffle+ crée désormais deux protections locales :

- une copie de récupération de la liaison complète lorsque l’espace est connecté ;
- une copie séparée de la dernière adresse serveur connue.

Si la clé principale `shuffleplus_server_sync_v1` disparaît mais que la copie de secours existe, la liaison est restaurée automatiquement. Si seuls les identifiants ont disparu, l’adresse Railway est au minimum préremplie afin d’éviter de créer un nouvel espace par erreur.

Une déconnexion volontaire supprime la copie contenant les secrets, mais conserve la dernière adresse. La suppression de l’espace distant suit la même règle.

## Migrations locales

Le schéma de stockage passe à la version 3. Les configurations sensibles suivantes ne sont plus supprimées automatiquement lorsqu’un JSON est illisible :

- connexion serveur ;
- copie de récupération serveur ;
- configuration du Client ID Spotify.

Elles sont signalées et préservées pour permettre une récupération manuelle.

## Diagnostic

Le rapport de diagnostic indique désormais :

- le mode Essentiel ou Expert ;
- la présence d’une sauvegarde de liaison serveur ;
- l’existence d’une dernière adresse serveur connue ;
- uniquement le nom d’hôte du serveur, jamais les jetons ni la clé de chiffrement.

## Compatibilité

La mise à jour conserve :

- Client ID et jetons Spotify ;
- playlists locales et bibliothèque hors connexion ;
- mix, profils et graines ;
- raccourcis iOS ;
- appareil Spotify préféré ;
- Dynamic Lyrics ;
- thèmes ;
- synchronisation locale et serveur ;
- statistiques et réglages avancés.
