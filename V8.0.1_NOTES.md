# Shuffle+ v8.0.1 — Correctif des Réglages

## Problème corrigé

Dans la v8.0.0, l’élément racine `<html>` utilisait `data-experience-mode` pour appliquer le mode Essentiel ou Expert. Le gestionnaire global des clics cherchait lui aussi le sélecteur `[data-experience-mode]`. Comme l’élément `<html>` est l’ancêtre de toute la page, chaque clic dans Réglages pouvait être interprété comme une nouvelle activation du mode courant.

Conséquences observées :

- message « Mode Essentiel/Expert activé » à chaque clic ;
- boutons Spotify, thème, PWA, sauvegarde et serveur bloqués ;
- formulaires impossibles à utiliser.

## Correction

Les boutons utilisent désormais un attribut distinct :

```html
<button data-select-experience-mode="expert">…</button>
```

Le gestionnaire écoute uniquement :

```js
button[data-select-experience-mode]
```

L’attribut `data-experience-mode` reste réservé à l’élément `<html>` pour le CSS.

## Données

Aucune donnée locale n’est modifiée ou supprimée : Client ID, connexion Spotify, serveur Railway, mix, raccourcis, thèmes et statistiques sont conservés.
