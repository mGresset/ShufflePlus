# Shuffle+ v4.2.0 — Feedback musical

## Nouveautés

- boutons J’aime, Pas maintenant et Trop répétitif dans le menu de chaque titre ;
- J’aime renforce la priorité du morceau ;
- Pas maintenant met le titre en pause pendant 7 jours ;
- Trop répétitif le met en pause pendant 30 jours ;
- les pauses sont appliquées aux prochaines générations et aux candidats Smart Queue ;
- affichage d’un badge sur les titres ayant un feedback actif ;
- tableau de synthèse et historique dans Intelligence ;
- filtre « Feedback musical » dans l’historique Intelligence ;
- réinitialisation globale des retours ;
- export et import JSON mis à jour ;
- aucun nouveau module JavaScript ajouté.

## Confidentialité

Les retours sont enregistrés uniquement dans le stockage local du navigateur. Ils ne sont pas envoyés à un serveur Shuffle+.
