Shuffle+ v5.4.0 — Adaptive DJ 2.0

1. Décompresser l’archive.
2. Remplacer les fichiers existants de votre dépôt ShufflePlus par ceux de cette version.
3. Publier sur GitHub :

   git add .
   git commit -m "v5.4.0 - Adaptive DJ 2.0"
   git pull --rebase origin main
   git push origin main

4. Attendre la publication GitHub Pages.
5. Ouvrir l’application puis Rechercher une mise à jour.
6. Fermer/réouvrir la PWA si nécessaire.

Astuce iOS : dans Adaptive DJ, utilisez le bouton « URL iOS » d’une scène pour coller le lien dans l’app Raccourcis.
