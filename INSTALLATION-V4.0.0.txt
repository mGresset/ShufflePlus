Shuffle+ v4.0.0 — Installation

1. Sauvegarder le dossier actuellement publié.
2. Remplacer son contenu par tous les fichiers du ZIP.
3. Ne pas oublier les nouveaux éléments :
   - manifest.webmanifest
   - service-worker.js
   - favicon.ico
   - dossier icons
4. Publier :

   git add .
   git commit -m "v4.0.0 - PWA installable"
   git pull --rebase origin main
   git push origin main

5. Attendre la publication GitHub Pages.
6. Ouvrir le site puis forcer une actualisation une fois.

Installation iPhone :
- Safari > Partager > Sur l’écran d’accueil > Ajouter.

Installation ordinateur / Android :
- utiliser le bouton Installer l’application ou le menu du navigateur.

Après une future mise à jour, utiliser le bandeau Mettre à jour ou :
Réglages > Application installable > Rechercher une mise à jour.
