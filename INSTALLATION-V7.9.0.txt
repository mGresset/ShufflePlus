SHUFFLE+ V7.9.0 — INSTALLATION RAPIDE

1. Appliquer ShufflePlus-v7.9.0-patch.zip sur le dépôt v7.8.1.
2. Dans Visual Studio Code :

   git switch main
   git pull origin main
   git switch -c release/7.9.0
   Remove-Item .\startup-recovery-7.8.1.js -ErrorAction SilentlyContinue
   npm run validate
   npm start

3. Tester http://127.0.0.1:5500/
4. Publier :

   git add .
   git commit -m "Release Shuffle+ v7.9.0"
   git push -u origin release/7.9.0

5. Créer puis fusionner la Pull Request.

La mise à jour conserve la connexion Spotify, les mix, les raccourcis,
l’iPhone préféré, Dynamic Lyrics, les thèmes et les données locales valides.
