# Shuffle+ v7.4.0 — Dynamic Lyrics et profils compagnons

## Objectif

La v7.4.0 ajoute Dynamic Lyrics comme application compagnon facultative des raccourcis iOS Shuffle+. Les paroles ne sont pas intégrées au mode conduite et aucun Client ID, access token ou refresh token de Dynamic Lyrics n’est stocké par Shuffle+.

## Fonctionnement

Shuffle+ utilise un raccourci personnel enregistré dans l’application Raccourcis d’iOS. Après le lancement réussi de la playlist ou du mix, Shuffle+ peut appeler ce raccourci avec le schéma officiel `shortcuts://run-shortcut`.

Le raccourci personnel doit :

1. porter le même nom que celui configuré dans Shuffle+ ;
2. utiliser une action Dynamic Lyrics lorsqu’elle est proposée sur l’iPhone, ou simplement l’action « Ouvrir l’app » vers Dynamic Lyrics ;
3. être testé une première fois depuis l’application Raccourcis pour accepter les autorisations éventuelles.

## Nouveautés

- nouveau panneau **Dynamic Lyrics** dans **Mix & iOS** ;
- activation globale de l’intégration ;
- nom du raccourci compagnon configurable ;
- délai configurable entre le démarrage Spotify et l’ouverture des paroles ;
- boutons **Tester** et **Copier le lien test** ;
- option **Ouvrir Dynamic Lyrics après le lancement** pour chaque commande Shuffle+ ;
- possibilité d’utiliser un nom de raccourci compagnon différent selon le profil ;
- paramètres `lyrics=1` et `lyricsShortcut=` ajoutés aux liens Shuffle+ ;
- bouton de secours **Ouvrir Dynamic Lyrics** après une lecture réussie ;
- prise en charge des playlists fixes et des mix intelligents ;
- sauvegarde, restauration et synchronisation des réglages Dynamic Lyrics ;
- interface responsive pour Safari et la PWA iPhone.

## Limites connues

- Shuffle+ ne lit pas les paroles et ne contrôle pas l’Activité en direct directement ;
- le contenu exact du raccourci compagnon dépend des actions proposées par la version de Dynamic Lyrics installée ;
- iOS peut demander une confirmation lors du premier appel au raccourci ;
- si l’ouverture automatique est refusée, le bouton manuel reste disponible dans l’écran de succès ;
- le compte Spotify de Dynamic Lyrics reste indépendant de celui de Shuffle+.

## Données locales

La configuration est enregistrée sous la clé :

```text
shuffleplus_dynamic_lyrics_settings_v1
```

Elle contient uniquement l’activation, le nom du raccourci, le délai et la date de modification. Aucun secret Spotify n’y est enregistré.
