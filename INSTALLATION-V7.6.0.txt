SHUFFLE+ V7.6.0 — INSTALLATION RAPIDE

1. Décompresser ShufflePlus-v7.6.0-patch.zip dans le dépôt v7.5.0.
2. Exécuter : npm run validate
3. Exécuter : npm start
4. Tester : http://127.0.0.1:5500/
5. Simulation iOS locale : http://127.0.0.1:5500/?debug_ios=1
6. Publier la branche release/7.6.0 puis fusionner la Pull Request.

NOUVEL UTILISATEUR
- Créer une application Spotify Developer.
- Ajouter https://mgresset.github.io/ShufflePlus/ comme Redirect URI.
- Coller uniquement le Client ID dans Shuffle+.
- Ne jamais saisir de Client Secret.
