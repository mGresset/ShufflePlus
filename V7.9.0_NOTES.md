# Shuffle+ v7.9.0 — Architecture et performances

## Objectif

Cette version améliore les fondations de Shuffle+ avant la v8.0.0. Elle ne retire aucune fonction et ne modifie pas la navigation, les profils iOS, le mode conduite ou le moteur de mélange visibles dans la v7.8.1.

## Chargement progressif

- ajout de `core/feature-loader.js` ;
- déduplication de deux demandes simultanées du même module ;
- suivi des états `idle`, `loading`, `loaded` et `error` ;
- mesure du temps de chargement ;
- chargement de `app-health.js` seulement à l’ouverture du Centre de diagnostic ou lors d’un export.

Cette première étape fournit le socle qui permettra de déplacer progressivement d’autres fonctions lourdes hors de `app.js` dans les versions suivantes.

## État d’exécution central

Le module `core/runtime-state.js` suit désormais les informations transversales suivantes :

- phase de démarrage ;
- état prêt ou erreur ;
- rubrique active et groupe principal ;
- connexion Spotify et type de compte ;
- modules secondaires chargés ;
- durée d’exécution et nombre de révisions.

Cet état ne contient ni titre musical, ni nom de playlist, ni identifiant Spotify personnel.

## Migrations sûres du stockage

Le module `core/storage-migrations.js` introduit le schéma local version 2.

Au démarrage, Shuffle+ :

1. inspecte uniquement les clés locales `shuffleplus_*` qui ressemblent à du JSON ;
2. détecte les valeurs illisibles ;
3. crée une sauvegarde de récupération avant toute réparation ;
4. retire uniquement la clé corrompue si la sauvegarde a réussi ;
5. conserve la valeur intacte si l’espace de sauvegarde est indisponible.

Les tokens Spotify, le Client ID et les valeurs non JSON ne sont pas traités par cette migration.

Clés techniques ajoutées :

```text
shuffleplus_storage_schema_v1
shuffleplus_storage_recovery_v1
```

## Diagnostic exportable enrichi

Le rapport passe au schéma 2 et ajoute :

- modules chargés à la demande ;
- durée de chargement ;
- état d’exécution ;
- version du schéma local ;
- nombre de réparations et de sauvegardes de récupération ;
- état du quota et du cache Spotify déjà présent.

Le rapport n’exporte pas les tokens, le Client ID complet, les playlists, les titres ou l’identifiant personnel du compte.

## Compatibilité

La mise à jour conserve :

- le Client ID Spotify personnel ;
- la session Spotify ;
- les playlists et caches locaux valides ;
- les mix et graines ;
- les raccourcis iOS ;
- l’iPhone préféré ;
- Dynamic Lyrics ;
- les thèmes ;
- les statistiques et objectifs ;
- les réglages de synchronisation.
