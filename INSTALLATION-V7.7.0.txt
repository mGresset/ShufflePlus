SHUFFLE+ V7.7.0 — INSTALLATION RAPIDE

BASE REQUISE
- Shuffle+ v7.6.0 stable.
- Ne pas installer la v7.6.1 avant ce patch.

1. Décompresser ShufflePlus-v7.7.0-patch.zip dans le dépôt v7.6.0.
2. Exécuter : npm run validate
3. Exécuter : npm start
4. Tester : http://127.0.0.1:5500/
5. Ouvrir une playlist et cliquer sur Mélange intelligent.
6. Vérifier le rapport Pourquoi cet ordre ?, la graine et Rejouer exactement.
7. Publier la branche release/7.7.0 puis fusionner la Pull Request.

AUCUNE DONNÉE SUPPRIMÉE
- Client ID et connexion Spotify conservés.
- Mix, profils, raccourcis et iPhone préféré conservés.
- Réglages, statistiques et cache hors connexion conservés.
