# Shuffle+ v8.2.0

## Objectif

Remettre la fonction d’origine de Shuffle+ au centre : lancer une playlist Spotify personnelle en mode aléatoire, sur l’appareil choisi, avec le moins d’actions possible.

## Lancement principal

L’accueil contient désormais un panneau dédié avec :

- le profil ou la playlist principale ;
- l’appareil de lecture attendu ;
- l’état du shuffle ;
- l’ouverture éventuelle du mode conduite et de Dynamic Lyrics ;
- un bouton **Lancer maintenant** ;
- un bouton **Copier l’URL iOS**.

Les profils iOS déjà enregistrés sont réutilisés. Le profil `principal` est choisi en priorité, puis le premier profil disponible. L’utilisateur peut sélectionner un autre profil comme lancement principal.

## Installation guidée en sept étapes

1. Application Spotify Developer configurée ;
2. compte Spotify connecté ;
3. playlist ou profil principal choisi ;
4. appareil Spotify prêt ;
5. lancement testé ;
6. raccourci iPhone confirmé ;
7. PWA Shuffle+ installée ou confirmée.

La progression est enregistrée localement et incluse dans les sauvegardes Shuffle+ ainsi que dans la synchronisation chiffrée.

## Mode Essentiel

La nouvelle installation guidée complète le mode Essentiel sans supprimer les fonctions avancées. Les utilisateurs existants conservent leur mode Expert.

## Compatibilité

- aucune modification du Client ID ou des jetons Spotify ;
- aucun changement de serveur Railway ;
- profils iOS, mix, thèmes, statistiques et appareils conservés ;
- mise à jour directe depuis la v8.1.0.
