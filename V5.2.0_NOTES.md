# Shuffle+ v5.2.0 — Mix Studio avancé

## Fonctions ajoutées

- jusqu’à 12 modèles Mix Studio réutilisables ;
- pondération individuelle de chaque source de 1 à 5 ;
- sélection pondérée des morceaux pour les durées cibles ;
- comparaison de trois variantes de génération ;
- application ou aperçu immédiat d’une variante ;
- sauvegarde, importation et synchronisation des modèles ;
- comparaison et fusion sélective des modèles entre appareils.

## Compatibilité

Le serveur Shuffle+ v5 reste inchangé : il transporte toujours un paquet opaque chiffré côté navigateur.

## Cache PWA

Le cache passe à `shuffleplus-v5.2.0-shell`.
