# Shuffle+ v3.4.0 — Adaptive Learning

## Nouveautés

- apprentissage local intégré au menu Adaptive DJ ;
- observation des lancements manuels, commandes iOS et changements de configuration ;
- calcul d’un niveau de confiance par créneau avec pondération de récence ;
- jusqu’à trois suggestions simultanées ;
- boutons Appliquer et Ignorer ;
- réapparition d’une suggestion ignorée uniquement après de nouveaux indices ;
- affichage des habitudes détectées ;
- activation ou désactivation sans effacement ;
- réinitialisation complète ;
- sauvegarde et restauration JSON de l’apprentissage.

## Sécurité fonctionnelle

- aucune association n’est modifiée automatiquement ;
- les lancements Adaptive DJ ne créent pas seuls une suggestion ;
- les tests de créneau sans lecture ne sont pas enregistrés comme préférences ;
- aucune nouvelle dépendance JavaScript ni nouveau module n’a été ajouté.

## Conservation

- 300 observations maximum ;
- fenêtre de 180 jours ;
- données stockées uniquement dans le navigateur.
