Shuffle+ v5.3.1 — Installation

1. Sauvegarder le dossier actuellement publié.
2. Remplacer tous les fichiers client par ceux du ZIP.
3. Le serveur Node.js existant ne doit pas être redéployé.
4. Publier :

   git add .
   git commit -m "v5.3.1 - Visual Polish and Accessibility"
   git pull --rebase origin main
   git push origin main

5. Dans Shuffle+ :
   Réglages → Rechercher une mise à jour.

6. Fermer complètement la PWA puis la rouvrir.

Le contraste renforcé se trouve dans :
Réglages → Apparence → Contraste renforcé.
