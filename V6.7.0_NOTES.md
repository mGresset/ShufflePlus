# Shuffle+ v6.7.0 — Visite guidée et aide contextuelle

## Nouveautés

- visite guidée automatique en six étapes lors de la première ouverture ;
- bouton « ? » disponible dans toutes les rubriques normales ;
- explication courte adaptée à la page affichée ;
- conseils dynamiques selon les éléments déjà configurés ;
- indications « Commence ici » pour les rubriques encore peu utilisées ;
- accès direct au Guide simplifié et au README détaillé ;
- panneau Aide et prise en main dans les Réglages ;
- possibilité de relancer, désactiver ou réinitialiser la visite ;
- suivi local des rubriques déjà consultées ;
- sauvegarde et restauration des préférences d’aide.

## Parcours présenté

1. Accueil ;
2. Ma musique ;
3. Mix & iOS ;
4. Adaptive DJ ;
5. Rapide ;
6. retour à l’Accueil.

Le mode Conduite conserve son interface plein écran sans bouton flottant supplémentaire.
