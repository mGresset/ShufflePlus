# Shuffle+ v6.8.0 — Recherche universelle

## Recherche depuis toutes les rubriques

Un nouveau bouton « Rechercher dans Shuffle+ » apparaît au-dessus du menu.
Il permet de retrouver rapidement :

- une rubrique de l’application ;
- une playlist Spotify ou les morceaux aimés ;
- un mix enregistré ;
- une scène Adaptive DJ ;
- un profil de mélange ;
- une routine programmée ;
- un contexte de commande rapide ;
- un réglage comme le thème, la sauvegarde, la synchronisation ou la mise à jour.

## Utilisation

- PC et Mac : `Ctrl + K` ou `⌘ + K` ;
- clavier : flèches haut/bas, Entrée et Échap ;
- mobile : bouton de recherche puis interface plein écran ;
- raccourci supplémentaire : touche `/` hors d’un champ de saisie.

Les recherches récentes restent uniquement dans le navigateur et peuvent être
effacées directement depuis la fenêtre de recherche.

## Navigation précise

Une playlist ouvre Ma musique avec son nom déjà recherché. Un mix, une scène
ou un profil ouvre la bonne rubrique et met brièvement en évidence la carte
correspondante.

## Assistant

La commande `Ouvre la recherche universelle` est reconnue par l’assistant
texte et vocal.

## Compatibilité

Aucune nouvelle autorisation Spotify et aucune modification du serveur Node.js.
