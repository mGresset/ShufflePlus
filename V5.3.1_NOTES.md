# Shuffle+ v5.3.1 — Visual Polish & Accessibility

Cette version stabilise le design Dynamique & Musicale introduit en v5.3.0.

## Corrections visuelles
- meilleure gestion des largeurs sur iPhone et ordinateur ;
- textes longs autorisés à revenir à la ligne sans élargir les cartes ;
- champs de formulaire à 16 px sur iPhone pour éviter le zoom automatique ;
- zones tactiles d’au moins 44 px ;
- marges compatibles avec les zones de sécurité iOS ;
- onglet actif recentré automatiquement dans la navigation du bas ;
- suppression des mouvements de cartes sur les écrans tactiles ;
- amélioration des petits écrans et du mode paysage.

## Accessibilité
- nouveau réglage « Contraste renforcé » ;
- textes secondaires plus lisibles ;
- messages d’état annoncés aux technologies d’assistance ;
- libellés accessibles sur chaque bouton de navigation ;
- animations réduites compatibles avec le réglage système.

## Compatibilité
- thèmes v5.3 conservés ;
- Mix Studio avancé v5.2 conservé ;
- synchronisation chiffrée v5 conservée ;
- serveur Node.js inchangé.
