Shuffle+ v6.0.0 — Installation

1. Sauvegarder le dossier actuellement publié.
2. Remplacer les fichiers du client par ceux du ZIP.
3. Le serveur Node.js existant ne nécessite aucune modification.
4. Publier :

   git add .
   git commit -m "v6.0.0 - Assistant musical local"
   git pull --rebase origin main
   git push origin main

5. Dans Shuffle+ : Réglages → Rechercher une mise à jour.
6. Fermer complètement la PWA puis la rouvrir.

Le nouvel onglet « Assistant » se trouve entre Adaptive DJ et Intelligence.
