# Shuffle+ v4.7.1 — Correctif `dataUpdatedAt`

## Problème corrigé

La v4.7.0 pouvait afficher dès l’ouverture :

```text
dataUpdatedAt is not defined
```

La fonction de sauvegarde référençait `dataUpdatedAt` avant qu’une valeur soit
calculée. Comme cette sauvegarde alimente aussi la préparation de synchronisation,
l’erreur pouvait interrompre l’initialisation générale de l’application.

## Correction

- les données sont assemblées avant le calcul de leur date de modification ;
- `getSyncDataUpdatedAt(data)` calcule ensuite la valeur ;
- le cache PWA et les fichiers versionnés passent à `4.7.1`.

Aucune donnée locale n’est supprimée. L’authentification Spotify, le moteur de mix,
le mode conduite et les profils rapides restent inchangés.
