# Shuffle+ v8.3.1

## Objectif

Uniformiser l’interface sans supprimer la personnalisation. Toutes les pages peuvent désormais s’appuyer sur un même système de composants et sur la palette choisie par l’utilisateur.

## Changements principaux

### Design system global

Un nouveau fichier `design-system.css` est chargé après `style.css`. Il consolide les styles historiques sans imposer une réécriture immédiate de l’application.

Il fournit :

- `ui-button--primary` pour l’action principale ;
- `ui-button--secondary` pour les actions normales ;
- `ui-button--ghost` pour les actions discrètes ;
- `ui-button--danger` pour les suppressions et réinitialisations sensibles ;
- des tailles, arrondis, bordures, ombres et transitions communes ;
- une présentation cohérente des champs, listes déroulantes et zones de texte.

### Correction des thèmes

Les écrans 8.2 et 8.3 employaient plusieurs noms de variables, notamment `--accent-color`, alors que le sélecteur de thème mettait principalement à jour `--accent`.

La v8.3.1 ajoute les alias nécessaires :

- `--accent-color` → `--accent` ;
- `--muted-text` et `--text-secondary` → `--text-muted` ;
- `--text-primary`, `--primary-text` et `--text-color` → `--text-main` ;
- `--border-color` → `--border-soft`.

Le thème sélectionné est ainsi appliqué aux composants récents comme aux écrans historiques.
