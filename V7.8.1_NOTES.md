# Shuffle+ v7.8.1 — Thèmes étendus et conduite personnalisée

## Mode conduite synchronisé

Le mode conduite ne conserve plus l’ancien vert fixe. Les éléments suivants utilisent désormais la couleur sélectionnée dans Shuffle+ :

- carte du contexte ;
- libellés du morceau en cours ;
- bouton principal ;
- retours musicaux actifs ;
- bouton Liste de lecture ;
- options cochées ;
- état actif du maintien de l’écran ;
- file de lecture ;
- messages de réussite.

Le fond reste volontairement sombre afin de conserver une bonne lisibilité en voiture. Les couleurs d’avertissement et d’erreur restent sémantiques.

## Raccourcis iOS en premier

Dans la rubrique **Créer**, **Raccourcis iOS** est maintenant la première section présentée. Le panneau de création et de gestion des commandes iPhone apparaît avant le studio de mélange, les mix enregistrés, les programmations et l’historique.

Cette modification remet la fonction initiale de Shuffle+ au premier plan sans supprimer le moteur de mélange.

## Couleur personnalisée

Un sélecteur et un champ hexadécimal permettent de choisir une couleur libre. Shuffle+ :

1. normalise le code couleur ;
2. affiche un aperçu avant validation ;
3. génère automatiquement une couleur secondaire ;
4. calcule un texte clair ou sombre adapté ;
5. applique la palette à toute l’application et au mode conduite ;
6. conserve la couleur dans les réglages existants.

Le bouton **Revenir au violet** restaure rapidement le thème par défaut.

## Compatibilité des données

Les anciens réglages de thème sont migrés sans intervention. Cette version ne supprime pas :

- le Client ID et la connexion Spotify ;
- les mix et profils ;
- les raccourcis iOS ;
- l’iPhone préféré ;
- les réglages Dynamic Lyrics ;
- les statistiques et objectifs ;
- les données hors connexion.
