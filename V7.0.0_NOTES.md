# Shuffle+ v7.0.0 — Stabilisation et navigation organisée

## Navigation réorganisée

Les rubriques sont maintenant regroupées en trois ensembles :

- Essentiel : Accueil, Ma musique, Mix & iOS, Rapide et Conduite ;
- Intelligence : Adaptive DJ, Assistant, Pour toi, Statistiques, Objectifs et Analyses ;
- Outils : Modes, Guide et Réglages.

Tous les intitulés restent sur une seule ligne. La barre conserve le défilement horizontal lorsque l’écran manque de place.

## Mémoire de position

Shuffle+ mémorise la position de défilement de chaque rubrique. Revenir dans une page longue ramène donc à la zone précédemment consultée.

## Centre de diagnostic

Une nouvelle section dans Réglages vérifie :

- la connexion sécurisée et le stockage local ;
- l’état du réseau ;
- le Service Worker et les caches PWA ;
- le mode application ;
- la disponibilité du maintien de l’écran ;
- la reconnaissance vocale, le presse-papiers et le partage système.

Le rapport peut être exporté en JSON sans données Spotify personnelles. Une action de réparation du cache PWA est disponible et ne supprime pas les mix, réglages ou connexions enregistrés.

## Stabilisation

- prise en charge directe de `?view=dashboard` ;
- restauration fiable des pages Pour toi et Statistiques ;
- cache PWA versionné en v7.0.0 ;
- serveur Node.js inchangé.
