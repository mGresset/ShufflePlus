Shuffle+ v3.3.4 — Installation

1. Sauvegarder le dossier actuel.
2. Remplacer les fichiers par ceux du ZIP.
3. Vérifier dans index.html :
   <script type="module" src="./app.js?v=3.3.4"></script>
4. Publier :

   git add .
   git commit -m "v3.3.4 - Adaptive DJ Menu Edition"
   git pull --rebase origin main
   git push origin main

Après publication :
- PC : Ctrl + F5
- iPhone : fermer Safari puis rouvrir.

Configuration :
- ouvrir le menu Adaptive DJ ;
- associer un mix à chaque créneau ;
- enregistrer ;
- copier l’URL iOS ;
- dans Raccourcis : ouvrir Spotify, attendre 1 seconde,
  puis ouvrir l’URL copiée.
