# Shuffle+ v4.8.0 — Fusion sélective

## Nouveautés

- aperçu détaillé local / distant ;
- six catégories de données ;
- choix Conserver local, Fusionner ou Utiliser distant ;
- préréglages Tout local, Fusionner tout et Tout distant ;
- déduplication par identifiant ;
- sauvegarde automatique avant modification ;
- journal de fusion.

## Sécurité

La synchronisation reste locale et manuelle. Aucun serveur n’est contacté et aucun jeton Spotify n’est exporté.
